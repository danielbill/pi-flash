## 大文件红线

test/ 只收三类东西：用例文档（case.md/testcase.md）、小驱动脚本、微型夹具。任何可能超过 1MB 的文件不入库——入库的只能是生成它的脚本（生成参数记进 testcase.md，产物落 gitignore 目录或 tmp/）；不可再生的大样本（真崩溃 dump 等）走黄金仓/外链并在此登记，不进本仓。
