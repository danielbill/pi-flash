# 084 会话查询（Session Search）

> 会话查询承载为 **083 同版式的面板**（内容区 tab）：**只查询**，无
> replace 之类复杂操作。013 为模块索引，现行设计以本文为准。

## 1. 结论口径

| 维度 | 083 项目搜索 | 084 会话查询 |
|---|---|---|
| 入口 | Ctrl+Shift+F / Ctrl+L / 文件树钮 | **Ctrl+K** / psp「搜索会话」钮（两个入口沿用） |
| 承载 | 内容区单例 tab `PanelTab::Search` | 内容区单例 tab `PanelTab::SessionSearch` |
| 搜索框 | 无 border（`TextInput::flat()`） | 同 |
| 开关列 | Aa / wd / .\* + 过滤 + 替换 | **无**（只查询：没有正则/大小写/整词/包含排除/替换） |
| 结果分组 | 文件块（组头 = 文件名 + 目录） | 会话块（组头 = 会话名 + 相对时间） |
| 组头版式 | `results::card_header` | **同一个函数**（不能各写一套） |
| 正文 | 行号 + 单色 + 命中底色 | 无行号（会话片段不是文件行）+ 单色 + 命中底色（同一个 `match_highlights`） |
| 结果列表 | `gpui::list` 虚拟化 | 同（`gpui::list` + `ListState`；**不要自建 `overflow_y_scroll` 容器**——长 URL 的最小内容宽会把它顶宽，右边距被吃掉） |
| 滚动条 | 常显 | 常显（`ListStateHandle` + `Scrollbar::vertical`） |
| 两侧边距 | `pl 8 / pr 18`（左侧由行号列提供视觉内缩） | **两侧等距 `pl 16 / pr 16`**（会话片段没有行号列） |
| 片段缩进 | 行 = 行号列 + 正文 | 片段行**左右各缩 24（`SNIPPET_INDENT`）**：左缘与组头标题文字**同一条竖线**、右缘同样收在组头之内 |
| 空态 | Zed landing page（标题 + 五条选项行） | 标题 `搜索会话` + 提示句（没有选项行——没有可点的开关） |

## 2. 数据与状态

- **范围 = 全部会话（跨项目）**：`pi_link::sessions::search_sessions_all` 遍历
  sessions root 下**所有** group 目录，各文件的会话按 mtime 倒序**全局混排**
  （最近聊过的先出），同一会话的命中仍连在一起；user/assistant 文本块、字面
  **不区分大小写**匹配；`SEARCH_MAX_RESULTS = 30`、每会话最多 5 条、3s 预算、
  最多扫 500 个文件，超限置 `truncated`（计数显示 `N+`）。
  （`search_sessions_for_cwd` 单项目入口保留，供其他调用方/测试。）
- **组头副标题 = 项目名 · 绝对时间（`10月21日 09:22`）**：项目名取会话文件
  首行 `cwd` 的末段（缺失时回落 group 目录名解码），UUID 形态的目录名只留
  前 8 位。时间用**绝对时刻**不用「2小时前」——同名会话（某些宿主应用每个
  任务都发同一段指令正文，标题天然一样）只有精确到分钟才分得清，否则看起来
  像「同一个会话头出现 N 次」。组头标题单行限长 64 字。
- **一个会话只有一个组头**：分组按会话路径建索引归并（不是只看「相邻」），
  命中序列即使交错也不会冒出重复组头；组序 = 首现序。
- 状态仍住 `PspState`（工作区级、切会话不丢）：
  `search_hits / search_truncated / search_running / search_needle / search_gen`
  加上 `session_query`（懒建输入框）、`session_collapsed`
  （收起集合，键 = 会话文件路径）、`session_scroll` / `session_sb_state`（滚动条）。
- 防抖 300ms + 代际丢弃陈旧响应（逻辑在 `sessions.rs`）。
- 新一次查询进来：清空结果、清空收起集合、滚动回顶。

## 3. 交互

- 打开/快捷键重触发 → 面板单例 tab + **当帧聚焦查询框**（`TextInput::focus_soon`
  在输入框自己那帧兑现，与 083 同一条；不要用「置 flag、下一帧补推焦点」）。
- `Esc` → 收起面板（defer 出帧再关：关 tab 会 drop 正在派发事件的输入框实体）。
- 组头收展钮（28×28，无 tooltip）：只收展该会话块，不跳转。
- 组头/片段行点击 → `jump_to_hit(会话路径, ts)`：切到该会话并定位到命中消息
  （会话未在池中则 `pending_locate` 等 reconcile 后补定位）。**面板不关闭**
  （与 083 打开文件后保留面板同一条）。

## 4. 结果视觉与计数

- 结果行视觉 = 中性 `bg_selected` 命中底色 + 正常字重，与 083 一致，两处面板
  用同一套 `match_highlights`。
- 命中计数 = 查询条右侧的 `N`（`truncated` 时 `N+`）+ 运行中转圈（与 083 的
  counter 同位同形）。

## 5. 测试

- `search::sessions::tests::groups_adjacent_hits_by_session`：相邻同会话命中归一块、
  换会话才开新块、组头标题回落链（会话名 → 预览 → 文件 stem）。
- 组头/正文版式继承 083 的回归锁（`real_blocks_render_with_height`、
  `adjacent_headers_keep_eight_px_gap`、`collapsed_block_keeps_only_header`、
  `match_spans_become_highlights`）——会话查询走的是同一批渲染件。
- 自动化：`pif-ui keys ctrl-k` → `snapshot app --only content_view` 应为
  `session_search`；`keys <词>` 打字后 `shot` 看图（本模块暂无专属 op）。
