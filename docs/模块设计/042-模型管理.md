此模块涉及供应商和模型管理。

代码模块：
- modelManager：`pi-link::models_config`（enabledModels 白名单语义）
- providerManager：`settings/models.rs`（页面）+ `settings/custom_models.rs`（自定义编辑器）+ `pi-link::registry`（全量注册表）/ `pi-link::probe`（通路探查）/ `pi-link::pf_providers` + `pf_auth`（自定义账本与凭据，051）

对应界面：
1、settings - 模型
2、inputpanel - 模型菜单

> 对齐原则：UI/行为以 pi-web 代码与截图为准（设置-模型.bmp、Provider清单页.png、
> 内置Provider设置页.png、模型菜单.bmp），不自行发挥；PF 特有改动仅限「定稿决策」清单。

## 定稿决策

1. **默认模型存 PF 自己的 `~/.pi-flash/app-settings.json`**（`default_provider`/`default_model` 两键，snake_case）：pi 的 settings.json 是系统 pi / pi-web 的地盘。应用链路：spawn 时以 `--model` 带给**全新草稿**（重绑/恢复的会话不动）；无默认时回落显示名序第一个。
2. **新增 Provider 弹窗只提供 内置（API KEY）+ 订阅服务 两组**：OAuth 登录归 pi、PF 不发起（051 边界，beads pi-flash-1cb），订阅卡点击仅提示未接入；自定义 provider 不设新增入口。
3. **保存 apikey 后自动探查通路**（PF 超出 pi-web 的优化）：保存即向该商列模型端点发一次轻量 GET，key 错误在保存时刻暴露（否则要重启会话才发现）。
4. **停用 ≠ 删凭据**：供应商/模型启停全部走 enabledModels 白名单（可逆，凭据保留）；删 key 只在详情页【断开连接】。

## 设计事实（pi-web 对齐依据）

- 模型目录与凭据无关：内置商模型列表来自 SDK 静态注册表（+ `models-store.json` 目录 overlay + 自定义账本），保存 key 后模型「可勾选」，列表本身常在。
- enabledModels 无 provider 字段：整商启停 = 白名单增删该商条目（从全启用态停用 = 写其余各商的经验证 glob）；全启用 = 无 `enabledModels` 键；侧栏 `x/N` 徽标仅白名单收窄时显示。
- 白名单语义：patterns 解析为空 = 全启用（pi 回落规则）；停用最后一个启用模型必须拒绝（last-model guard）；失配（stale）条目对编辑不可见、永不触碰。
- 会话内切模型（菜单点行）是会话级的（RPC `set_model` 不落盘）；落盘的只有星标默认模型。
- 051 联动：key 存系统凭据库、`pf-auth.json` 只留变量名、spawn 注入官方 env 名；换 key 注入子进程环境，**运行中会话需重启才生效**。

## settings - 模型

左栏 = 单一合并列表；右栏 = 详情。无页面级 banner / footer（改动即写盘；models.json 不可读的错误挂详情区错误条，保存禁用逻辑保留）。

```
┌─────────────────左栏─────────────────┐
│ 【+ 添加Provider】                    │
│ ⛨ Z.AI Coding CN    1/4  [开关]      │ ← 默认模型所在 Provider 置顶
│     GLM-5.3-Flash               ★    │ ← 该商启用模型平铺（★ = 默认，唯一）
│ ⛨ DeepSeek          1/2  [开关]      │ ← 有启用模型的
│     DeepSeek V4.1 Flash         ☆    │
│ ⛨ OpenAI            0/44 [开关]      │ ← 没模型的沉底
└─────────────────┬────────────────────┘
                  └ 右栏：详情（API KEY 表单 + 探查行 + 可用模型区 / 自定义商编辑器）
```

- 合并列表（单一 vlist 虚拟化，全表等高行）：
  - Provider 行 = 图标 + 显示名 + `x/N`（白名单收窄时）+ switch。switch = enabledModels 整商切换（内置/自定义一致）；未配置 key 的内置商恒关禁用，点行进详情配 key。
  - 模型行 = 缩进槽 + 显示名 + thinking pin 徽章 + 五角星，与菜单共用组件（`group_model_row`）；行不可点（设置页无会话语义）。
  - 排序三档：默认模型所在 Provider → 有启用模型的 → 没模型的；档内按 Provider 显示名字典序（内置/自定义混排），组内模型按显示名字典序。
  - 过滤框：启用总数 ≥10 才显示（`MODEL_FILTER_MIN`，与菜单同规则，阈值以下文本不参与过滤）；只筛模型行，Provider 行常驻。
- 默认模型（五角星）：实心 = 当前默认（全局唯一）；点星写 app-settings 并同步设置页与菜单；再点 = 取消（回落排序第一）。
- Provider 详情（内置商）：状态点 + 配置落点文案（系统凭据库 / 文件存储 / 高级引用）+ key 输入（placeholder「ENV 变量、!命令 或明文 key」，显示/隐藏切换）+【保存】+【断开连接】+ 探查行。
- 自定义商详情：表单头【保存】/【移除】即写盘（043 同款）；模型子表单增删。
- 可用模型区：已启用 x/N + 全部开启/关闭 + 筛选（>8 出现）+ 行开关（last-model 守卫）+ vlist 虚拟化。

### 通路探查（决策 3）

- pi-link 固化 `内置商 id → (列模型 URL, 鉴权样式)` 端点表（13 家，URL/鉴权对齐 pi-web `lib/model-discovery.ts`：openai 系补 `/models`、anthropic `x-api-key` + `anthropic-version`、google `x-goog-api-key`）；表外商（含自定义商）跳过探查。
- key 按 `$PF_KEY_*` 引用从凭据库解；明文/`!cmd` 引用不探查。
- 三态：通过（延迟 + 模型数）/ key 被拒（401/403）/ 网络不可达（附原因）；20s 超时。
- 结果只驱动探查行文案与状态点，不回滚保存；通过后提示「新会话生效；运行中会话需重启后可用」。

### 新增 Provider 弹窗

- 数据源 = SDK **全量注册表**（非凭据过滤后的 available）：`pi-link::registry` 起一次性 node 走 SDK API（`ModelRuntime.create({refreshOnCreate:false})` + `getProviders()/getModels()/listCredentials()`）dump，落 `~/.pi-flash/registry-cache.json`，vendor VERSION 为缓存键；providers 非空但计数为空视为失败（不落缓存）。
- 版式：近满窗大面板 + 顶部全宽搜索（分隔线压底）+ 滚动卡片网格（卡 = 左名称+副标题、右 provider 图标，无图标走首字母兜底）。
- 组序：**API KEY → 订阅服务**。API KEY = 声明 `auth.apiKey.login` 且无 api_key 凭据，副标题 `N models`（registry 全量计数，与启用开关无关）→ 点击进详情 API KEY 表单；订阅服务 = 声明 `auth.oauth` 且无 oauth 凭据，副标题 `OAuth`，点击提示未接入。
- 组内保持 registry 原始顺序；已配置的商不列（`!configured`/`!loggedIn` 同款）；PF 自定义账本的商不进 API KEY 组；搜索：API KEY 匹配显示名/id、订阅匹配显示名。
- 打开弹窗即后台拉注册表（缓存命中同步可用），未就绪/失败显示状态行。
- 弹窗挂载在 settings 之后（后渲染者在上，否则遮挡层吃掉点击）。

## inputpanel - 模型菜单

- 锚定模型钮的 pill 菜单（与扩展/MCP 菜单同机制、统一定位算法）；顶部过滤输入按 `MODEL_FILTER_MIN` 阈值显隐，↑/↓/Enter 键盘导航。
- 按 provider 分组，组头 = provider id 大写；行 = ✓槽位（当前会话模型）+ 显示名 + pin 徽章 + 五角星。
- 点行 = 会话级切换（`set_model`）；点星 = 设默认（写 app-settings，与设置页同一份、双向同步）。
- 数据走 Chat 共享目录（`catalog_for`），无进程草稿照常弹出。

## 程序设计

- `pi-link/src/models_config.rs`：白名单全量语义（pattern 匹配 / glob 展开 / `:level` pin / stale 保留 / last-model 守卫 / 整商开关），单测看护。
- `pi-link/src/registry.rs`：全量注册表 dump + 缓存（vendor VERSION 键、空计数守卫），分组/凭据过滤/OAuth 显示名覆盖表（openai-codex→ChatGPT Plus/Pro、github-copilot→GitHub Copilot）为纯函数，单测看护。
- `pi-link/src/probe.rs`：端点表 + 三态探查；`pf_providers.rs`/`pf_auth.rs`：自定义商账本与 key 分流（051）。
- `app/src/session/model_picker.rs`：菜单 + 两处共用组件（`group_entries` / `group_header_row` / `group_model_row` / `MODEL_FILTER_MIN`）+ 注册表后台拉取（`ensure_registry`/`RegistryState`）。
- `app/src/settings/models.rs`：设置页合并列表（三档排序）/ 详情 / 探查行 / 星标（写 app-settings 并扇出全部 runtime）。
- `app/src/dialogs.rs`：`render_provider_picker`。
- 自动化面：`model.picker_open` op + 快照键 `model_rows`（语义：可见模型数）。
