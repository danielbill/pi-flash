## 项目会话 tab（左端，「项目」briefcase 图标）

020-1 起面板 tab 只剩「项目」一个：46px 常亮连体卡（nav 底、顶无边、
底圆角、accent 图标），整合面板常驻后暂为纯指示位——点击回整合面板
（DockPanel::Default）。文件树 tab 已隐藏（文件树并入上方整合面板），
tab 位保留，新面板可在此续接（切换走 layout.dock_panel）。

## PF 插件 tab

插件清单 `contributes.status_bar` 声明 → 46px 连体卡（「项目」tab 同形），
点击按清单形态开左列 dock 面板或内容区预览页签；禁用插件不出 tab。
