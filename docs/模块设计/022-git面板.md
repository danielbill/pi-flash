完全按照zed的git面板实现

模块代码：gitPanel

## UI设计简化

PF 定位傻瓜化（个人单机，非团队 git 工具），底部状态栏的 git tab 入口已删
（当前不可达路径仅剩 automation `panel.dock`——git 面板保留独立视图挂在
`function_panel/mod.rs` 的 dock 分支）。后续简化方向（未做）：只留 Stage All / Unstage All + Commit/Push 主按钮 + History tab，砍掉 stash 系列与 discard 类危险操作。

面板本体（`git_panel.rs` + `changes/` + `history/`）：头部单行（项目名 +
Changes(N)/History tabs 右靠）；Changes 页 = View Diff + Stage All 操作行、
变更树（目录嵌套 + 文件复选，勾/去勾 = stage/unstage 单文件）、底部
branch/↑N Push + 融入式 commit message 大区 + Commit Tracked 钮 + 最近
提交条（含 uncommit 撤销）；History 页 = 提交列表 + 逐条 push 小钮。

## 刷新后台化

`refresh_git` 的两个子进程（`git status --porcelain=v1 -z
--untracked-files=all` + `git diff --numstat HEAD`，暖盘各 ~90ms）整体走
background executor（`cx.spawn` + `background_spawn`），跑完换入 + notify，
不占主线程。

- **守卫**：`ws.git_refresh_gen` 请求序号 + `ws.git_files_cwd`——换项目或 fs
  watch 合批泵又发起新刷新时，在途陈旧结果直接作废（最后一次说了算）。
- **换项目瞬间**：`git_files`/`git_add_del` 先清空（`git_files_cwd`
  不等时换入前不留上一个项目的痕迹）；branch 显示 = `ws.branch`，换项目时
  由 `services/format.rs read_branch`（读 `.git/HEAD`）同步读取，即时更新。
- **无项目态**：清空 git 面（无工作区即无状态），照常走换入守卫。
- **调用面**：全部调用点（git 面板按钮、树文件动作（新建/改名/移动/删除）、
  自动化 git.* op、启动装载、fs watch 合批泵）统一传 `cx` 走后台刷新回读。
