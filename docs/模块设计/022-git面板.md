## UI设计简化

PF 定位傻瓜化（个人单机，非团队 git 工具），git 面板**暂缓设计**，底部状态栏 git tab 图标已隐藏（status_bar.rs 注释掉入口行，恢复走 git 历史）。后续简化方向：只留 Stage All / Unstage All + Commit/Push 主按钮 + History tab，砍掉 stash 系列与 discard 类危险操作。



## 刷新后台化（pi-flash-9rk0）

`refresh_git` 的两个子进程（`git status --porcelain` + `git diff
--numstat`，暖盘各 ~90ms）整体走 background executor（`cx.spawn` +
`background_spawn`），跑完换入 + notify，不占主线程。

- **守卫**：`git_refresh_gen` 请求序号 + `git_files_cwd`——换项目或 fs
  watch 合批泵又发起新刷新时，在途陈旧结果直接作废（最后一次说了算）。
- **换项目瞬间**：`git_files`/`git_add_del` 先清空（`git_files_cwd`
  不等时换入前不留上一个项目的痕迹），branch 同步读 .git/HEAD 仍即时。
- **实测**（pif-ui 隔离实例）：暖 `project.switch` 190-313ms → 106-126ms；
  换完瞬间 files=0 → ~1.2s 内新项目改动清单换入；fs watch 落/删文件
  自动出现/消失；`git.stage` 等写动作后同样经后台刷新回读。
- 调用面（14 处）全部改传 `cx`：git 面板按钮、树文件动作（新建/改名/
  移动/删除）、自动化 git.* op、启动装载、fs watch 合批泵。
