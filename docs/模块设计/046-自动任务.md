### 1.5 交互规则汇总

| 规则 | 方案 |
|---|---|
| 弹层方向 | 本页全部浮层(⋯菜单/下拉)走 `ui::popup::PopupEdges` 统一算法:上半向下弹/下半向上弹 |
| tooltip | 一律 `with_tip`(350ms 手势),禁止自写 hover 状态机 |
| 确认 | 删除任务 = 小确认弹窗 380 档:文案 + 右对齐按钮行,确认钮 Danger 变体;运行中任务删除先中止再删(文案注明) |
| 立即运行 | ⋯菜单触发,run 标 manual;任务运行中再点 = 菜单该项置灰(opacity 0.5) |
| 运行中状态刷新 | 列表/历史行状态点由调度泵状态驱动 `cx.notify()`,不自建轮询 UI |
| 打开会话 | 打开 = `open_session` 正式 tab;窗口保持开启(用户可继续管理) |
| dev-flag | `auto_tasks` 关:按钮/窗口/泵三处同源不出现 |
