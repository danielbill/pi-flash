app 界面设置主要包括主题、字体、字体大小、文件树文件图标集等。
这些都要保存在 app_settings.json 中。

这里参考zed的 appearance 设置

- theme
- icon theme
- session font （等于zed的UI font）
- panel font 
- markdown preview font

## 主题theme
theme架构使用zed
内置几套主题 —— 
浅色： pi-web的 【雾青】【蔷薇】， zed的【One Light】【nord light】【ayu light】
深色： zed的【One Dark】【nord dark】

## icon theme
icon theme 架构使用zed
内置图标主题使用 pi-web自带的icon主题。

## markdown preview 
zed的markdown preview非常糟糕
使用 pi-web的markdown preview
