app 界面设置主要包括主题、字体、字体大小、文件树文件图标集等。
这些都要保存在 app-settings.json 中（读写单点 `services/workspace/app_settings.rs`）。

参考zed的 appearance 设置：

- theme
- icon theme
- session font （等于zed的UI font）
- panel font
- markdown preview font

## 主题theme

色板代码单点 `appearance/theme.rs`（语义 token；UI 组件规范唯一代码落点 =
`ui/kit` tokens）。Zed 三套色板自 zed 官方 assets 移植，雾青/蔷薇承 pi-web
观感，其余自研或移植自 VS Code/Obsidian 主题底子。内置十套主题（`theme::ALL`）——

浅色： 雾青（mist，pi-web 默认观感）、蔷薇（rose）、薰衣草（latte）、
秋叶（kitchen）、One Light（one-light）
深色： Monokai Pro（monokai-pro）、Noctis（noctis）、
Night Owl（night-owl）、Nord Dark（nord-dark）、One Dark（one-dark）——前三者主题名不译；
松林（pine）已从注册表隐藏（2025-11，PINE_FOREST 常量保留可回归）

主题选择：`PI_FLASH_THEME` env（开发覆盖）> app-settings.json。
