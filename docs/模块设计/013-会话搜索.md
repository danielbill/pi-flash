# 013 会话搜索（会话查询）

现行设计见 [084-会话查询](084-会话查询.md)：与 083 同版式的内容区单例 tab
（`PanelTab::SessionSearch`，Ctrl+K / psp「搜索会话」钮打开），只查询、无替换。

- 模块代码：`crates/app/src/search/`（`sessions.rs` 会话查询面板；`mod.rs` 与
  083 文件搜索共用的查询框/结果渲染件）
- 搜索引擎：`crates/pi-link/src/sessions.rs`——`search_sessions_all` 全量跨项目；
  `search_sessions_for_cwd` 单项目入口保留，供其他调用方/测试
- 状态：`PspState`（工作区级）：`session_query` / `search_hits` / `search_truncated` /
  `search_running` / `search_needle` / `search_gen` / `session_collapsed` /
  `session_scroll` / `session_sb_state`
