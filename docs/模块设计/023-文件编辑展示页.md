按照 zed 的文件编辑区实现（简化对齐，非复刻全部功能）

模块代码：`crates/app/src/editor/`——`kind.rs` 文件类型注册表、`view.rs`
（+ `view/bar.rs` 导航栏、`view/surfaces.rs` 非编辑展示面）视图、`tabs.rs`
（+ `tabs/` 打开/保存/冲突/关闭/持久化）tab 生命周期、`file_content.rs`
编解码、`markdown/` md 渲染与 024/025。文件打开/缓冲区状态（file_cache）
在 Chat（`shell/` 域）。

## 布局

左侧是文件树（021，功能面板内），右侧是文件视图（`ContentView::File`），
占满功能面板右侧整个内容区，经 topbar 标签带与会话/终端等视图互斥切换
（005）。

## 该视图主要组件
自上而下：

- 标签栏（并入 topbar，不在本视图内自绘）
文件 tab 与终端 tab 等混排于 topbar 自由标签区：标签区限宽
（flex_1 + min_w_0），超出横向滚动、不侵吞右簇（对齐 Zed tab bar）；
激活 tab 滚进视口（`activate_panel_tab` 唯一 `scroll_to_item` 写点）。
tab 行尾标记：冲突 `!` > 脏点（amber）；磁盘已删 = tab 删除线（不标
`!`）。激活/背景 tab 等高。tab 顺序稳定 = 打开序（激活不重排，浏览器
同款）；文件 tab 有 soft cap（047），满时逐出最旧非脏 tab。文件动作
（新建/改名/删除等）入口在文件树右键菜单（021）。

- 导航操作栏（`view/bar.rs file_nav_bar`）
该栏分为左右两块。左侧 = 面包屑（对齐 zed 可点击面包屑）：cwd 相对路径
段逐级可点，点开「兄弟文件菜单」列同目录文件（截断 200）；工作区外文件
退化为绝对路径段。右侧 = kind handler 声明的工具钮（默认仅搜索；md 追加
eye 双态切换）。

- 编辑展示区
主体分发零类型特判（`file_editor_body` → kind handler `render_body`）：
1、代码变色（tree-sitter）
2、文件编辑（gpui-component CodeEditor，见「编辑器底座」）
3、markdown 双态：源码态编辑 / eye 切 preview 渲染页（024）
4、图片查看 tab（图片后缀按字节 magic 认领，gpui img() 只读查看）与
   「无法打开 {ext} 类型文件」灰屏（带默认应用兜底按钮）
5、外部改动变动检测（对齐 ZED，见「默认约定」）

- 编辑区右键菜单（状态槽 `Chat::editor_menu`，渲染挂 psp_overlays 同层）
  - 编辑块：复制 / 粘贴 / 剪切 / 全选（全类型共有）
  - 文件动作块（kind handler `menu_file_actions`）：html/htm 首位
    「在浏览器中打开」；md 源码态首位「预览」；在资源管理器中打开；
    在终端中打开（所在目录）；改名；删除（删除到回收站）

构建目标：极速、最小文档编辑功能、代码变色、markdown 预览、搜索。

## 编辑器底座

**不语义自研，简化对齐 zed。** 文本缓冲区/光标/undo/IME 不自己写，用
vendored gpui-component 0.2.0 Input 的 **CodeEditor 模式**（行号 +
tree-sitter 高亮 + 内置搜索替换弹层 + 章节折叠箭头/indent guides，
折叠见 024 §8）：

- 我们做的是**对齐工作**：键位、编辑行为、外观对齐 zed editor；
  砍掉 LSP、多光标、补全、悬浮文档等高级功能
- 高亮语言随 `tree-sitter-languages` feature（vendored 带 26 个语言包，
  `tree-sitter-sequel`/`tree-sitter-ruby` 因 MSVC 编不过已剔除）；kind
  注册表按后缀启用其中各语言，未注册后缀纯色显示
- 行高 1.618（Zed BufferLineHeight::Comfortable 档；vendor 补丁让
  code editor 模式吃继承值）；族+字号随「文档字体」槽位
  （`appearance::file_font`）
- 注入语言高亮（HTML `<style>`→css、`<script>`→javascript）做解析成品
  缓存 + 查询按可见行裁剪，计量/复核见 050 §二与 `docs/agents/gpui.md`
- 编辑器配色映射：`appearance::sync_gpui_tokens` 补映射
  `highlight_theme`（gutter/当前行/背景专用 token，默认停暗色盘）；
  语法配色用组件内置明/暗盘

## 实施补记

1. **文件树点击一律进 fileView**；diff 入口收敛在 git 面板（022）。
2. **html/htm 并入代码类处理器**：html/htm 与 xml/vue/svg 共用一个
   CodeKind（ts "html"）；「浏览器项打头」差异由路径判据
   `editor::kind::browser_openable` 决定，编辑器右键菜单与文件树菜单
   共用（两处扩展名规则不各写一份）。html 编辑器右键菜单仍首位

## 默认约定

- 保存 Ctrl+S（action `FileSave` 绑 Input 上下文，编辑器聚焦时命中）；
  未保存修改 tab 显示脏标记圆点；关闭脏标签弹确认；**自动保存恒开**
  （1s 防抖，Zed after-timeout 同构，`tabs/save.rs`）
- 外部改动检测（fs watcher 泵合批信号跑 `check_external_file_changes`，
  按 disk_sig 复查）：**监听面 = cwd 递归 watch + cwd 外打开文件按所在
  目录单挂非递归 watch**（`retain_file_watches`，Zed 为 workspace 外文件
  建 single-file worktree 同款）。缓冲区无未保存修改 → 自动重载，重载用
  `reload_value`——保留阅读位置/光标（set_value 是程序化赋值语义，会把
  光标扔到文末、滚动归零）；有修改 → tab 标记冲突，横幅裁决（重新加载 /
  保留我的版本，对齐 Zed）。文件从磁盘消失 = Deleted：缓冲保留可继续
  编辑、tab 删除线是唯一标记、保存即重建，不弹横幅（zed
  DiskState::Deleted 同构）。markdown 预览同理不因块数变化跳回顶部
  （滚动锚点恢复），且**有未保存修改时预览渲染缓冲区**（Zed preview 读
  buffer，不是磁盘文件）
- 二进制/超大文件（>10MB）提示不打开（状态条）；目录路径 → 资源管理器
  打开；图片后缀再按字节 magic 认领开图片查看 tab；解不出的二进制 →
  灰屏 tab 照开（让用户看见是哪个文件），主体带「默认应用打开」兜底钮
- 面包屑 = 项目根相对路径段，可点击逐级导航（对齐 zed）；**工作区外文件
  退化为绝对路径，Windows 盘符前缀与根合为一段（`D:\` 一个 crumb，
  不再是 `D:` + `\` 两段）**——分段与累积路径由
  `view.rs breadcrumb_segments` 单一实现，渲染与自动化快照共用
- **自动回行（soft wrap）全程开启**：所有 kind 的 `EditorConfig.soft_wrap`
  恒 true（vendored gpui-component `soft_wrap(true)` 增量折行）；md 预览
  靠块内容段 `min_w(0)` 拿到确定宽度自然折行（zed markdown 同款
  `min_w_0`）
- 文本解码/编码保真（`file_content.rs`）：打开按 BOM/UTF-16/chardetng
  嗅探，保存按 tab 记录的磁盘编码回写（UTF-16/遗留编码/BOM 往返保持，
  不静默转 UTF-8）

## 搜索面板

- **token 映射**：`sync_gpui_tokens` 按应用 token 映射 gpui-component 的
  `popover/popover_foreground/secondary_*`（popover 留给 tooltip/菜单；
  popover 相对 bg_panel 混 4% text 抬升——`mix_rgb(a,b,wa)` 的 wa 是
  **a** 的权重，主色放第二参）。
- **样式对齐 zed**：搜索条全宽平贴、背景 = 编辑器背景（与上方面包屑
  操作栏同色，非浮卡）；全部按钮加本地化 tooltip（区分大小写/切换替换/
  上下个匹配含快捷键/关闭），文案在组件 `locales/ui.yml`，locale 随
  `i18n::set_lang` 同步（繁体走组件 zh-HK 桶）；启动时无条件
  `set_lang(load_lang_pref().unwrap_or(0))`。
- **结构归位（搜索框是操作栏的一部分）**：面板不挂在编辑器 TextInput
  顶部（vendor `text_input.rs` 摘掉 `.children(search_panel)`，升级重放
  时勿漏），由 app 操作栏 `file_nav_bar` 作为第二行渲染
  （`InputState::search_panel_element()` 返回面板元素 +
  `search_panel_open()` 控制占位）——面包屑行与搜索行同块同底色，× 与
  右侧图标列同缘，Esc 收起整行。
- **折叠/WYSIWYG 态搜索高亮**：命中 quad 经 vendor 显示空间换算收口
  （`element.rs quad_span` → `offset_to_display_point`），跨折叠段与软
  换行不错位。
- **Ctrl+F / Ctrl+H 分职**：Ctrl+F 只出搜索行；Ctrl+H（action
  `SearchReplace`）出搜索+替换两行；替换行对齐 zed——placeholder
  「替换为…」、Replace/Replace All 为 ghost 图标钮（上游 replace-all.svg
  资产 + vendor IconName::ReplaceAll）；Tab/Shift+Tab 字段环转对齐 zed
  cycle_field；Esc 整体收起。
- **焦点**：app 的帧级焦点仲裁（render 每帧回收焦点给 composer）不认识
  搜索面板的输入框——它不是编辑器本体的 focus_handle。vendor 补丁：
  `SearchPanel::inputs_focused` + `InputState::search_panel_focused`
  （均在 `input/search.rs`，升级重放）；`Chat::file_editor_focus` 把
  面板持焦视同编辑器持焦。
- **图标资产**：SearchPanel 的 Aa/替换/‹/›/× 用 gpui-component 的
  `IconName`（`icons/*.svg`），上游 crate 不带 assets，宿主 app 的
  `Assets` 补嵌 lucide 图标（case-sensitive/replace/chevron-left/close，
  源：上游 crates/assets/assets/icons）。
- **编辑区右键菜单**：编辑块（复制/粘贴/剪切/全选，派发 Input 动作前先
  归位焦点）+ 文件动作块，样式与文件树菜单同套（menu_card/menu_item/
  menu_sep）。vendor：编辑器内置 MouseContext 菜单（英文 PopupMenu）
  摘除——Right 降级为「无选区移动光标」，宿主接管右键（升级重放清单：
  state.rs Right 分支）。
- **自动化**：`input.focus` 增 `editor` 目标（Ctrl+F 类「焦点在编辑器才
  生效」的键位断言入口）；编辑菜单开合走 `file.context_menu` /
  `file.context_menu_close`（置状态槽，与真右键同路），见
  000-自动化测试.md。
- 已知限制：查询为字面量匹配（aho-corasick），无整词/正则开关。

## FileTypeHandler 注册表架构

文件类型决策收口为 `editor/kind.rs` 的 **FileKind 注册表**：按后缀名注册
handler，未注册一律走默认文本 kind（TextKind）。调用点（打开路由/编辑器
配置/主体渲染/工具栏/右键菜单）零 if-else——新增文件类型 = 声明 kind 静态
量 + 注册表登记一行，框架不动。

- **handler 职责**：`editor_config`（tree-sitter 语言/软换行/025 图片粘
  贴钩子；None=无编辑器类型如图片）、`try_binary`（图片字节 magic 认领，
  zed `ImageItem::try_open` 同构）、`render_body`（主体渲染算法）、
  `toolbar`（默认仅搜索；仅 md 追加 eye）、`menu_file_actions`（右键菜
  单文件动作块，含分隔线；md 源码态带预览项）、`supports_view_mode`
  （双态门控，file.view_mode op 对非双态类型静默成功）
- **kind 清单**：TextKind（默认；ts "text" 纯色）/ CodeKind{语言}（txt
  与 code 是两个 kind；html/htm/xml/vue/svg 共用 ts "html" 的那个）/
  MarkdownKind（双态，默认源码态；唯一挂 025 图片粘贴钩子）/
  ImageKind{格式}（img() 查看器，无编辑器）。csv 等未注册后缀自然落
  TextKind
- **不进 kind 的路径判据**：`browser_openable`（html/htm）——「在浏览器中
  打开」只由一个判据决定，编辑器右键菜单与文件树菜单（021）共用，不再
  为它单开一个 kind
- **共享基建不管类型**（对一切已打开 tab 统一生效）：文本缓冲/脏位/自动
  保存/外部改动检测/冲突横幅/搜索面板/面包屑/焦点仲裁/章节折叠（024 §8）

### html 打开行为

html/htm **不开系统浏览器，直接开源码 tab**（tree-sitter html 高亮、
可编辑、共享自动保存/外部改动全套基建）。「在浏览器中打开」为 html
右键菜单首位文件动作（MenuAction，与文件树菜单 021 同款）。注册表当下
没有需要路由旁路的类型，无旁路钩子。
