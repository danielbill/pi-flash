# 042-2 模型价格管理

## 要解决什么问题

自定义模型没价格时落 `{0,0,0,0}`，ctx 面板「累计费用」恒 $0.0000。
需要一个**快速、准确、可单模型查询**的价格源。

价格源 = `sst/models.dev` 仓库按模型 TOML（4KB/个、免鉴权、官方波谷价）；
整包 api.json（5.3MB）拉不动，OpenRouter 是高峰转售价（口径不一致），
硅基流动是转售价还要 key。

```
https://raw.githubusercontent.com/sst/models.dev/dev/providers/{dir}/models/{model}.toml
https://cdn.jsdelivr.net/gh/sst/models.dev@dev/providers/{dir}/models/{model}.toml  ← CN 兜底
```

`providers/deepseek/models/deepseek-flash.toml`：cost 0.15/0.6/0.003 = 官方波谷价，头注释引用官方定价页。

## 在哪个模块使用

- **`crates/pi-link/src/model_price.rs`**：解析链 `models.dev TOML 单源 → Err（调用方维持 0，手填兜底）`。OpenRouter 降级源已删——高峰转售价与 TOML 波谷口径不一致，双源等于双口径，价格口径统一波谷。
- **`crates/app/src/settings/custom_models/probe.rs`**：`mj_catalog_fill`【自动填参】调 `model_price::resolve`，暂存/保存落盘语义不变（只填空/零；缓存 TTL 内先用缓存，否则拉网，网络失败回陈旧缓存）。
- **模型详情编辑器**：价格四输入框（$/MTok：输入/输出/缓存读取/缓存写入），**手填=显式覆盖**（与自动填参的只填空相反），落两处（清单仓 + models.json）。
- `models_json::normalize`（每次 save 都过）剥掉清单仓私有键 `priceSource`（单点闸门；pi 账本 schema 不认）。
- 启动/勾选零联网（热路径铁律）；价格只在用户点填参时后台拉。

## 调用哪个 API

- 请求：`GET providers/{dir}/models/{model}.toml`，raw 8s 超时失败换 jsdelivr。
- `{dir}` 猜测梯子（404 即下一个候选，不阻断）：baseUrl host 核心段（剥 `api.`/`open.` 等服务前缀）→ 内置别名表十几条（`dashscope→alibaba` 等）→ 清单仓商名 slug（`provider_dir_candidates`）。
- `{model}` 候选 = 现有 `model_ref::query_candidates(id, name)`。
- 解析只认 `schema = 2`：`cost.text.input.price` / `output.price` / `input.cache.read` / `cache.write`（缺省 0）；`limit.context/output` 顺带入填参条目（仍只进表单）；`multipliers`（高峰分时）读即丢（pi 账本无时段分档）。
- 全 miss → 0（手填兜底；聚合网关两边都猜不中，价格编辑器就是为它设计的）。
- 缓存 `~/.pi-flash/model-price-cache.json`，TTL 7 天，网络失败回陈旧；写入时顺手清理超 90 天的旧条目。
