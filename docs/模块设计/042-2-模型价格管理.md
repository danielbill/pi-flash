# 042-2 模型价格管理

## 要解决什么问题

自定义模型没价格时落 `{0,0,0,0}`，ctx 面板「累计费用」恒 $0.0000。
需要一个**快速、准确、可单模型查询**的价格源。

选型（2026-11-04 实测）：
models.dev 整包 api.json 5.3MB 拉不动；
OpenRouter 是高峰转售价（DeepSeek 差 2 倍）；
硅基流动是转售价还要 key。

**定稿：`sst/models.dev` 仓库按模型 TOML**（4KB/个、免鉴权、官方波谷价）：

```
https://raw.githubusercontent.com/sst/models.dev/dev/providers/{dir}/models/{model}.toml
https://cdn.jsdelivr.net/gh/sst/models.dev@dev/providers/{dir}/models/{model}.toml  ← CN 兜底
```

实测 `providers/deepseek/models/deepseek-flash.toml`：cost 0.15/0.6/0.003 = 官方波谷价，头注释引用官方定价页。

## 在哪个模块使用

- **`crates/pi-link/src/model_price.rs`（新）**：解析链 `TOML → OpenRouter::resolve_many（现有） → None落0`。新增 `toml` 依赖。顺手删死文件 `models_dev.rs`（未注册进 lib.rs）。
- **`crates/app/src/settings/custom_models.rs`（现有）**：`mj_catalog_fill`【自动填参】的 `openrouter::resolve_many` 调用点换成 `model_price::resolve`，暂存/保存落盘语义不变（只填空/零）。
- **模型详情编辑器**：新增价格四输入框（$/MTok，i18n 死键 `models.edit_costs` 系列复活），**手填=显式覆盖**（与自动填参的只填空相反），落两处（清单仓 + models.json）。
- `models_json::normalize`（每次 save 都过）剥掉清单仓私有键 `priceSource`（单点闸门；pi 账本 schema 不认）。
- 启动/勾选零联网（热路径铁律）；价格只在用户点填参时后台拉。

## 调用哪个 API

- 请求：`GET providers/{dir}/models/{model}.toml`，raw 8s 超时失败换 jsdelivr。
- `{dir}` 猜测梯子（404 即下一个，不阻断）：baseUrl host 核心段 → 内置别名表 ~15 条（`dashscope.aliyuncs.com→alibaba` 等）→ 清单仓商名 slug。
- `{model}` 候选 = 现有 `model_ref::query_candidates(id, name)`。
- 解析只认 `schema = 2`：`cost.text.input.price` / `output.price` / `input.cache.read`（缺省 0）；`multipliers`（高峰分时）读即丢（pi 账本无时段分档）。
- 全 miss → OpenRouter → 0。缓存 `~/.pi-flash/model-price-cache.json`，TTL 7 天，失败回陈旧。

测试钉子：TOML fixture 解析单测 / 梯子纯函数 / 投影剥 priceSource / 离线 run.sh（`test/042-2/`）。
