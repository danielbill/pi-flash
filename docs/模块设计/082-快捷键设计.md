## 设置中单独加一页 【快捷键】 说明

## 全局快捷键

- 打开项目 Ctrl + P
- 新建会话 Ctrl + N
- 搜索会话 Ctrl + K
- 搜索文件 Ctrl + L
- 最大化会话列表 Alt + 1
- 最大化文件树 Alt + 2
- 向左切换视图 Ctrl + <-
视图切换到当前标签左侧视图（composer/终端/预览等焦点生效；模态/弹层、编辑器搜索面板与编辑器本体退回组件词移动；编辑器内 Ctrl+←/→ = 词移动；边界 = no-op 死键）
- 向右切换视图 Ctrl + ->
视图切换到当前标签右侧视图（分流规则同上）

全局键均为无上下文绑定（`main.rs` `cx.bind_keys`，None context = 任意焦点可用）；Ctrl+←/→ 例外——Zed Pane 模式双绑定锚定：`Some("ContentTabs")` 命中内容区任意后代焦点 + `Some("Input")` 同深度后注册抢组件词移动（文件编辑器本体例外，退回词移动）。

## 文件树快捷键
- 改名 F2   
选中文件或目录时（点击/右键留存的选中态；F2 = 右键菜单「改名」同一路径，挂渲染根 on_key_down 兜底——故意无 action 绑定，防抢输入框词移动；终端焦点下 F2 发 PTY 不拦截）

## 版式

居中索引表格（600px 列）：

- 无页标题（弹窗头已有页名）；
- 组标题 = `全局 ——— 8 条`：组名 semibold + 细线延伸 + 条数；
- 行 = 名称/副说明 + 点线引导（1px 盒内 dashed 底边）+ 键帽；无行编号；悬停整行淡 accent 底（group/group_hover）；
- 键帽平面样式：细边框 + 底部 1px 厚边（外层深底衬 pb 露出——gpui 边框单色，用两层 div 模拟键帽侧面），主键面板白浮起、修饰键（Ctrl/Alt/Shift/Win）浅一档灰、字降一级；方向键显示 ←/→ 符号；
- 键位来源：六项 action（打开项目/新建会话/搜索会话/搜索文件/最大化两键）走 keymap 反查 `highest_precedence_binding_for_action` 首键（单一事实源，改绑定自动跟随），Ctrl+←/→ 与 F2 无 action、键串静态解析；
- 说明行只有文件树「重命名」需要（其余行不写说明）。
