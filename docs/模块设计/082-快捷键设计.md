## 设置中单独加一页 【快捷键】 说明

## 全局快捷键

- 打开项目 Ctrl + P
- 新建会话 Ctrl + N
- 搜索会话 Ctrl + K
- 最大化会话列表 Alt + 1
- 最大化文件树 Alt + 2
- 向左切换视图 Ctrl + <-
视图切换到当前标签左侧视图
- 向右切换视图 Ctrl + ->
视图切换到当前标签右侧视图

## 文件树快捷键
- 改名 F2   
选中文件或目录时

## 版式

居中索引表格（600px 列）：

- 页标题「键盘快捷键」（placeholder 色 text_faint）+ accent 短横线；
- 组标题 = `01 全局 ——— 7 条`：编号 accent mono + 组名 semibold + 细线延伸 + 条数；
- 行 = 01..08 跨组连续编号 + 名称/副说明 + 点线引导（1px 盒内 dashed 底边）+ 键帽；悬停整行淡 accent 底、编号转 accent（group/group_hover）；
- 键帽平面样式：细边框 + 底部 1px 厚边（外层深底衬 pb 露出——gpui 边框单色，用两层 div 模拟键帽侧面），主键面板白浮起、修饰键（Ctrl/Alt/Shift/Win）浅一档灰、字降一级；方向键显示 ←/→ 符号；
- 键位来源不变：五项 action 走 keymap 反查（单一事实源），Ctrl+←/→ 与 F2 静态解析。
