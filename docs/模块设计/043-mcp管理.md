mcp服务的注册和管理

模块代码：mcpManager

对应界面：
1、settings - mcp
2、inputpanel  - mcp菜单

## settings - mcp UI

去掉项目配置，只做全局配置

左侧为MCP注册列表，参考对齐 扩展列表，有总开关，也可单独开关

右侧为【MCP配置页】——
title：配置MCP

UI设计如下：
第一行 title ：配置MCP    |    右侧【保存】按钮
第二行 单行input：MCP名称
第三行 inputarea ：
8行高的inputarea;  placeholder : "粘贴 JSON/url/命令行/pi mcp add..."
第四行 四种说明 ——
```
- JSON：给出示例内容（注意，取消原先的点击互动，纯文本）
- URL：同上
- 命令行：同上
- pi命令：同上
```
