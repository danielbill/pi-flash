# 044-1 Settings-子代理页与 Agent 定义管理（宿主侧）

> 状态：**现行**。实例观测、会话流卡、导航次级弹窗见 `044-0`；扩展侧机制见 `044-5`。
> **开关分两层**：
> 1. **构建门**（开发旗标，默认开）：`dev-flags.json` `"subagents"` 或 env `PI_FLASH_SUBAGENTS`；关 = 发布包排除本模块——不加载扩展 + 隐藏本页 + 隐藏操作栏按钮，同源 `dev_flags::dev_enabled()`。
> 2. **运行时开关**（用户面，本页「模块」行）：写 pf-context hub `Subagents.enabled`。关 = 不挂 `pf-subagents` 扩展 ⇒ `agent` / `subagent_*` 工具压根不注册。工具面是 **spawn 参数**（RPC 无运行时切换），故翻开关要重绑进程：`Chat::apply_subagent_switch` 空闲会话立即重绑（`--session` 复接不丢消息）、运行中的会话由 `rebind_pending` 推迟到下一轮空闲发送。挂载决策唯一入口 `pi_link::subagents::mount_target(host_allows)`，宿主视角 = `subagent_module_active()`（两层相与）。

## 0 概念分层

```
Agent 定义(profile)= 用户资产 = 「类」     ← Settings-子代理页管理
  预制:扩展随包出厂(只读,可复制为自定义)
  自定义:用户完全所有(可建/改/删/分享/进项目 git)
子代理实例 = 运行记录 = 「对象」            ← 导航次级弹窗监视(044-0)
  委派产生的运行记录(childId/会话文件/状态/usage)
pf-subagents 扩展 = manager(机制层)        ← 不拥有定义,只消费目录
```

**存放 = 用户资产惯例，非扩展私有数据**：

| 来源 | 路径/载体 | 说明 |
|---|---|---|
| 自定义（全局） | `<PF数据目录>/agents/*.md`（env `PI_SUBAGENTS_PROFILES_DIR` 注入） | 用户完全所有：可建/改/删；同名覆盖内置 |
| 自定义（项目） | `<cwd>/.pi-flash/agents/*.md` | 项目级覆盖全局 |
| 内置 | 扩展代码内常量 | 随 pf-subagents 出厂，只读，可复制为自定义 |

**解析顺序（同名覆盖）**：项目 > 全局 > 内置；都无 → `PROFILE_INVALID`。

边界：

1. **不做包分发**——PF subagent 是内部组件，不对外发布，无 `pi install` 入口
2. **编辑走 PF 表单**，不让用户直写明文（§1.1）
3. PF 只表单化 v1 字段集（§2）；扩展新增的未知字段**原样透传不碰**

## 1 Settings-子代理页

### 1.1 定位与表单化

**Agent 定义的类型层管理**（观测面板是实例层）。形态与 042 模型管理同构（左列表右编辑）。

**配置项组件化，不让用户直写明文**；配置由 PF **单独管理存储**，不依赖手工改明文 md。

### 1.2 交互稿

```
Settings → 子代理
┌ 列表 ─────────────────┐  ┌ 表单详情 ─────────────────┐
│ 内置(随扩展,只读)      │  │ code-reviewer [自定义][覆盖内置]│
│  ○ explorer  只读探索  │  │ 描述     [代码评审_________] │
│ ──────────────────────│  │ 模型     [deepseek-chat ▾]  │
│ 自定义                  │  │ 轮次预算 [− 15 +] 默认100     │
│  ● code-reviewer 覆盖* │  │ 人格     [追加到默认|完全替换]│
│  ● broken-scan 损坏    │  │ 系统提示词 [多行文本________] │
│                        │  │ 工具     (read)(grep)(glob)…│
│ [+ 新建子代理]         │  │ ────────────────────────── │
│                        │  │  [放弃] [保存]  ●未保存 Ctrl+S│
└────────────────────────┴────────────────────────────┘
```

- 列表两组：**内置（只读）** / **自定义**；覆盖内置的自定义条目加「覆盖内置」badge
- 表单字段：描述 / 模型（下拉，留空继承会话）/ 轮次预算（步进器）/ 系统提示词（多行文本）/ 注入 AGENTS.md（开关，默认开）/ 工具档位（下拉）
- 不做：颜色标记、作用域选择、人格二档切换（提示词统一追加语义；schema 的 `systemPrompt` 替换字段保留但 UI 不暴露）
- 动作：放弃 / 保存（Ctrl+S，未保存黄点）；删除进**回收站**
- 内置态：表单只读灰化 + [复制为自定义]（fork 进自定义目录）
- 损坏态：红条错误（解析失败定位）+ [打开文件修复]（源码编辑器，表单化的唯一源码逃生口）+ [删除]；fail-closed 是运行时职责，PF 保证可修

### 1.3 存储

单一事实源 = `<PF数据目录>/agents/*.md` + 项目 `<cwd>/.pi-flash/agents/*.md`；CLI `pi -e`、PF、扩展共享同一目录。Settings 页 = 表单编辑的用户面，读写该目录。

## 2 字段集 v1（frontmatter）

```yaml
description: 代码评审          # 列表展示
model: provider/id            # 路由;UI 首项「继承」= 键省略
tools: inherit                # 工具档位(044-0 六档):inherit(委派者)
                              #    / chat-only / read-only / default / full
                              #    / full+(full+ 可选 pi-ext 与 mcp 服务)
maxTurns: 100                 # 轮次预算:软限(到限 steer 收尾,超限 abort,
                              #    stopReason: max_turns);UI 五档
                              #    5 / 30 / 100 / 不限(写 0) / 指定(键省略 = 主代理
                              #    派发时给 maxloop);默认「指定」
                              #    委派级 maxloop 可覆写(优先级 maxloop > maxTurns > 100)
                              #    5 档 = 内置摘要机的固定预算(2026-11-10 加档,
                              #    面板可选,不另造语义)
systemPrompt: |               # 替换式人格(优先于追加);走 pi
  你是代码评审员…               #    before_agent_start 的 systemPrompt override
appendSystemPrompt: …         # 追加式(与替换并存,替换优先)
injectAgentsMd: true          # 项目 AGENTS.md 是否注入子代理上下文(默认 true)
skills:                       # 注入的 skills,三态(键存在性是语义):
  - skill-name                #   键省略 = 继承系统开启集
                              #   裸键(下面无条目)= 关闭(内置 explorer/
                              #     summarizer 用它)
                              #   有清单 = 自定义
extensions:                   # full+ 档:挂载的 pi-ext 清单
  - path/to/ext.ts
mcp:                          # full+ 档:允许的 mcp 服务名清单
  - server-name
```

追加/替换语义对齐 pi 官方 SYSTEM.md / APPEND_SYSTEM.md 两档。

后续字段（不进 v1）：`inheritContextLimit`、`isolation`(worktree)、输出契约。

## 3 创建入口

| 入口 | 场景 | 成本 |
|---|---|---|
| **对话创建**（Creator 模式） | "帮我建一个 code-reviewer 子代理" → 主代理写一个 `agents/*.md` | 零开发（工具描述加一句引导） |
| Settings 页 [+ 新建子代理] 表单 | 手工从零建 / 复制内置改 | 低 |

不做包分发/分享入口（内部组件）。

## 4 数据与渲染契约

- 宿主观测**全部来自主会话**（子会话不回补主会话任何东西）：caller 交付看工具 result details，background 交付终态看父会话 `subagent-completion` custom 消息回灌
- 宿主 1s 常驻任务纯内存推导（落点映射 + 导航第三行点阵），零 IO（检索层设计见 044-3）
- 面板与导航卡共用同一份投影；不依赖扩展 `ctx.ui.setWidget`（`widgetLines` 只能是字符串数组，撑不起整行点击；该通道保留给通用扩展挂件，与本面板无耦合）
- 打开子会话 tab 标题 = 主会话反查 args（label → profile → prompt 首行），零读盘
