会话列表和文件树整合到一个面板。

## 面板结构分上下两部分
1、会话列表子面板
2、文件树子面板

默认两个面板各占据50%高度（`dock_split` 持久化，workspace 记忆文件）。
2个面板之间的分隔线可拖拽，改变各面板高度比例显示区域；拖拽即退出两侧
最小态、双击复位 50%。

各子面板至多收起到该面板的控制栏，所以各子面板都由 控制栏+内容区 两部分组成。

## 子面板最大化钮
每个子面板控制栏最右一颗「最大化」钮（maximize icon）：点击时本面板填满
dock、另一面板收起到它的控制栏。最大化态立即落盘（`UiState.dock_max`，
"none"/"sessions"/"files"，经 `dock_max_from_min` ↔ `layout.sess_min /
files_min` 唯一映射），重启恢复。再点恢复常态（分隔线占比回归）。

## 会话列表子面板
- 控制栏（`psp_view.rs psp_ctrl_bar`）：
  高度 38px（`tokens::panel_ctrl::BAR_H`），无下 border。
  左侧 icon+文字两颗（大图标 LG18）：项目（打开项目）、会话（新建会话）。
  右侧纯 icon 三颗（小图标 MD16，钮盒 26）：搜索（会话查询 Ctrl+K 同入口）、
  列表切换（项目分组 ↔ 最近会话，图标随模式换）、最大化。
- 内容区 ： 同 020。

## 文件树子面板
构造同 021，操作栏最右侧为最大化钮；项目名 = 主题色 + 粗体
（与项目列表选中行一致）。

## 注意事项
- 2个控制栏使用统一38px高度（`panel_ctrl::BAR_H` 38 / 钮盒 `BTN_H` 30）。
- 控制栏一律无下border。
- 被选中项目，项目列表和文件树，项目名称都统一为主题色粗体。
- 左缘对齐线 = ICON_LINE，右缘 = LIST_PX，两排右缘图标逐列对齐
  （最大化列同 x）。
- statusbar 的面板 tab 只剩「项目」一个（briefcase 图标，常亮连体卡；
  文件树 tab 隐藏——文件树已并入整合面板）；插件全屏功能页不占 statusbar
  图标位（入口收三横菜单）。

## 自动隐藏icon按钮
为减少视觉冗余，控制栏低频钮常态隐藏（opacity 0），鼠标进入本控制栏
（group 显影）才显示；钮盒位置/命中区不变（列对齐不抖）。

1、会话列表子面板 - 操作栏
自动隐藏右侧三颗：搜索、列表切换、最大化。

2、文件树子面板 - 操作栏
六颗钮（Pin / 只看变更 / 搜索 / 资源管理器 / 终端 / 最大化）全部自动隐藏。

--
总开关在 settings - 界面：【部分操作隐藏】（`settings.autohide_icons`），
switch，默认为 on。on 为隐藏；关掉则各钮恒显。
