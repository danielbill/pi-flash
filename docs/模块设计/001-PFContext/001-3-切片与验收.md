## 3 测试覆盖

**Rust（`crates/pf-context`）**

- `settings/tests.rs`：优先级 L0–L3（`precedence_l0_to_l3`）、未知键逐字往返
  （`unknown_keys_survive_write`）、坏档保好快照 / 坏 section 段级回退、
  并发 get/set、watcher 自写回声吃掉 + 外部改动重载、v1→v2 整份升级、
  flush 写失败内存保留、coalesce 合并与同内容跳过、dev-flags 永不落位
  （`s2_dev_flags_boot_only_never_written`）、pfctx.log 留痕（`s7_*`）、
  agent section（`s8_*`）。
- `settings/export.rs`：exportable 白名单过滤、同 payload 跳写保
  `generated_at`、敏感键硬闸。
- `state/`：快照语义 + 并发读写。
- `domain/db.rs`：WAL 与 schema 版本、迁移、事务回滚、并发写排队、新库拒绝。

**app（`crates/app`）**

- 桥：`pfctx-manager-op` 条目 → op 队列 FIFO + session 归属；其它自定义条目
  不串台（`session/runtime/events/on_event.rs::pfctx_bridge_tests`）。

**扩展（`node --test`，`npm test`）**

- pf-subagents `test/module-config.test.ts` + `test/projection.test.ts`：读段 /
  version 不匹配 / 文件缺失 / 半截 JSON 的返回值与 `problem`；回退顺序
  投影 → legacy → FALLBACK；坏投影不改变在跑上限。
- pfctx-manager `test/manager.test.ts`：目录校验（键/类型/枚举/范围）、恒拒
  项、注册形态。

**端到端（`#[ignore]` 门控，需已配置模型）**

- `cargo test -p pi-link --test live_pfctx_manager_probe -- --ignored --nocapture`
  ：真 spawn pi → agent 真调用 `pfctx_manager` → 宿主契约条目
  （customType=`pfctx-manager-op`）上事件流。

驱动：`node test/001-PFContext/run.mjs`（A 工具面 + B 挂载链守卫）。

## 5 与其他模块的关系

- **044 子代理**：扩展读取走投影段（[001-2 §4](001-2-跨进程投影.md)）；口径
  同步见 `044-5` / `044-0`。
- **046 自动任务**：任务定义/运行走 `domain`（SQLite）；per-project 参数走 L2 项目段。
- **100 管家**（设计稿，[100-0](../100-PF管家/100-0-管家总体设计.md)）：待办与
  记忆规划走 `domain`；行为参数走 L1/L2 settings。
- **042-1 模型管理**：`models.json`/`auth.json` 是 pi 的文件，不进 context；
  只有 `default_provider`/`default_model` 指针在 settings。
- **043 MCP**：`mcp.json` 编辑走既有 mcp 模块，不并入投影。
