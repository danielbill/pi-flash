# project manager
管理项目打开，查找、列表、删除等。

模块代码：`crates/app/src/dialogs/project_picker.rs`（打开项目弹窗）+ `crates/pi-link/src/projects.rs`（项目注册表）

触发按钮：
1、项目会话列表上方的 【打开项目】icon（psp）
2、新会话页 inputpanel 下方的 【打开项目】 icon
3、无项目态 composer 发送的「打开项目」门（010 send 门）同走本弹窗

## 打开项目

内容：
- 搜索框（按项目名过滤）
- 打开文件夹按钮 【打开文件夹】（走 psp 目录选择器；无 30 天活动项目时的主入口）
- 本机项目列表：按字母排序列出最近30天有会话活动的项目（项目注册表里
  打开过但零会话的项目同样入选，同一 30 天窗口；目录已删的注册项不再出现；
  一个 cwd 一行，聚合键走 ws 归一化——Windows 盘符/大小写、正反斜杠差异
  同项目合并）；列表吃满弹窗剩余高度（弹窗固定500高，容纳几条显示几条），
  超出出滚动条，不按固定行数限高

高500px， 宽500px，居中显示

注：默认选中当前项目行；当前项目不在列（列表未回填/被搜索词滤掉）时取
首个项目行，连项目行都没有才落【打开文件夹】

选项目的落点：
- 新会话页来源（012 操作栏）：选中 = 切换到该项目并落**全新草稿**（不恢复
  该项目上次打开的会话）
- 项目会话列表来源（psp icon）：选中 = 切换项目并恢复上次打开的会话
  （icon tooltip「打开项目」）
- 【打开文件夹】落点跟随来源
