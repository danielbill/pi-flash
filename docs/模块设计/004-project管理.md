# project manager
管理项目打开，查找、列表、隐藏、删除等。

模块代码：projectManager

触发按钮：
1、项目会话列表上方的 【打开项目】icon
2、新会话页 inputpanel 下方的 【打开项目】 icon

## 打开项目
见 【打开项目菜单.png]
内容：
- 搜索框
- 打开文件夹按钮 【打开文件夹】
- 本机项目列表：按字母排序列出最近30天打开过的项目；列表吃满弹窗剩余高度（弹窗固定500高，容纳几条显示几条），超出出滚动条（v3：不按固定行数限高）

高500px， 宽500px，居中显示


注：如果是从某项目新建会话，则默认选中该项目

选项目的落点（2026-10-07 定稿）：
- 新会话页来源（012 操作栏）：选中 = 切换到该项目并落**全新草稿**（不恢复
  该项目上次打开的会话——用户是要在这里开新会话）
- 项目会话列表来源（psp icon）：选中 = 切换项目并恢复上次打开的会话（既定
  行为，tooltip「恢复上次打开的会话」）
- 【打开文件夹】落点跟随来源
