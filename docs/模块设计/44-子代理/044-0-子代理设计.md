## 内置的subagent
1、通用子代理（id: general-purpose）
通用任务执行agent，和主agent没区别
适用场景：完全体的agent，能力大小只取决于扩展多少
- 继承委派agent的环境，CWD、注入全局和项目的AGENTS.md
- 工具集：默认full+配置 ，但如果委派agent也是full+，则继承
- skills：默认注入全局+cwd skills

2、本地探索者（id: explorer）
有只读权限的本地资料检索agent，专门用来查看任务相关的本地文件内容
适用场景场景：帮委派者做本地资料收集调研总结
- 继承委派Agent的环境，CWD、注入全局和项目的AGENTS.md
- 工具集：readonly
- skills：默认关闭

3、摘要机（id: summarizer）
无状态的摘要机器人，阅读指定文件或一段内容，按要求总结
适用场景场景：启用本地模型或云端廉价模型做系统日志摘要等
- 不继承环境，no cwd ， no AGENTS.md
- 工具集：readonly
- skills：默认关闭

## 子代理 模块设置
1、嵌套深度：默认为1（禁止套娃），可配 1-3
2、最大并发：2-5 ， 默认3（glm服务器侧只允许3个并发）
3、模块开关：**默认关**（开发旗标 dev-flags.json `"subagents"` / env `PI_FLASH_SUBAGENTS`，非用户设置项；发布包恒关）

传导链（2026-11-07 定稿，改完即生效）：设置页写 `<PF数据目录>/app-settings.json`（`subagent_capacity` / `subagent_max_depth`）→ spawn pi 注入 env（`PI_SUBAGENTS_CAPACITY` / `PI_SUBAGENTS_MAX_DEPTH` 作初值 + `PI_FLASH_APP_SETTINGS` 设置文件绝对路径）→ 扩展**每次委派 execute 前实时重读**设置文件同步 manager——env 是进程级快照会过时，实时重读保证不重启生效。

## subagent可设置项目
0、名称
1、使用说明： 简述该subgent用途
2、定制指令： 为其设置定制化的system prompt，这是追加指令，附加在Pi系统指令之后

6、最大轮次：max_loop , subagent最多可自主运行多少轮。  50 | 100 | no_limit | custom  ， custom由主agent指定，默认100
7、模型 ： 继承 | 预设 ，默认继承； 
8、工作目录：继承 


## 主Agent派发任务时设置项

主agent通过调用 `agent` 工具派发任务，PF UI 不参与分派，只经 descriptor 观察。调用时可设置：

1、prompt（必填）：完整任务陈述。
子代理默认看不到主会话上下文（spawn），任务必须自包含；委派者只等结论，不重复自己能委派出去的检索

2、profile：点名子代理身份（内置或自定义），决定其人格/工具档/默认模型/轮次预算；不点名则落系统预设默认子代理（general-purpose），不存在无 profile 的裸分身

3、model：临时模型覆盖，`provider/model` 全名；与 profile 自带 model 同时给时，本项优先

4、cwd：子代理工作目录，缺省继承委派者

5、label：任务短标签，展示在 transcript 与子代理面板

6、maxloop：本次任务预估轮次预算，0=不限，省略=100；子代理到预算会收到收尾引导，无视则被截断（max_turns）

7、background：true = 后台交付，立即返回 childId、完成后通知；缺省 = 等待跑完，结果作为普通工具结果返回（caller 模式）

派发约束（自动生效，无需主agent设置）：
- 嵌套深度自动 +1，超过模块 maxDepth 拒绝（DEPTH_LIMIT）
- 并发槽按父会话计数，满则拒绝且不排队（CAPACITY_REACHED）
- 同帧多条委派真并行执行（executionMode: parallel）

派发后的干预：subagent_send 追加指令 / subagent_interrupt 中断 / subagent_list 列出子代理。

## descriptor 字段总表（version 1）

事实源 = 父会话 JSONL 的 `subagent/descriptor` custom entry（**只在相位变迁/终态 `appendEntry`，同 childId 末条覆盖**。2026-11-07 用户定夺删除「每次状态变化实时 appendEntry」：逐条 assistant message 重发曾以 ~15 条/秒把父会话灌到 209MB / 29.9 万条 descriptor，会话打开全链路 O(文件) 全部被拖垮。运行期 stats/usage 只更新内存 descriptor——`children` 工具实时可读；面板运行中行停留在激活快照，终态落盘补齐，「不能统计就不统计」）：

| 字段 | 类型 | 落盘时机 |
|---|---|---|
| version | 1 | 创建时 |
| childId | sub-N（N 全局递增，被拒也消耗序号） | 创建时 |
| parentToolCallId | 父 `agent` 工具调用 id（nested 为 `<parent>/<n>`） | 创建时；导航面板按轮归属的钥匙 |
| provider | spawn / fork | 创建时 |
| label | 任务短标签（委派级） | 创建时 |
| profile | 子代理 profile id | 创建时 |
| model | `provider/id`（委派级覆盖或 profile 自带） | 创建时 |
| cwd | 子代理工作目录 | 创建时 |
| depth | 委派深度（父+1） | 创建时 |
| sessionFile | 子会话 JSONL 绝对路径 | **prepare 返回即回写**（运行中面板行可点开）；settle 再确认 |
| composition | {model, systemPrompt, tools} 快照 | 创建时（resume 还原用） |
| phase | provisioning → active → completed / interrupted / failed | 每次变化重发 |
| stopReason | completed / aborted / error / max_turns（终态才有） | settle |
| errorCode | 稳定分码（max_turns 终态 = MAX_TURNS） | 失败/截断时 |
| usage | {input, output, cacheRead, cacheWrite, total, totalTokens, cost} | **仅内存逐轮累计**（message_end 求和；children 工具实时可读），**settle 终态落盘**（2026-11-07 定夺：运行期不落盘，见上）；B1 修：caller 投递下 watcher 守卫须 settled/failed 才拦，`state!=="active"` 曾吞掉整个运行期上报 |
| stats | {turns, agentMessages, toolCalls} | **仅内存逐轮累计**，settle 终态落盘（2026-11-07 定夺：运行期不落盘） |
| startedAt / updatedAt | ISO-8601 | 创建 / 每次落盘（相位变迁/终态） |

被拒委派（CAPACITY_REACHED 等）也落一份 `phase:"failed"` descriptor——面板即时红行（B3③）。

## 子代理错误管理

错误码分两层，只维护自己产生的，不追模型商码表：

- 模块层（准入/控制）：DEPTH_LIMIT / CAPACITY_REACHED / PROFILE_INVALID / START_REJECTED / ADMISSION_CLOSED / ABORTED / PROVIDER_UNKNOWN / BACKEND_UNSUPPORTED / DUPLICATE_CHILD——稳定码全集，语义归 PF，码表可控
- 运行层（模型商产生）：429/5xx/超时/断流等不可枚举，一律归一为 PROVIDER_ERROR，原始报错保留在 message 不丢信息

原则：宿主与主agent永远拿得到稳定码；分类只区分「我们的 / 模型商的」，后续细分从 message 提取，不动码表。

## 子代理Max_loop管理

软限两段式，不硬砍：

1、预算解析：调用级 maxloop > profile maxTurns > 默认100；0=不限（不装计数器）
2、到限先引导：steer 注入收尾指令（禁止新工具调用，立即总结作答），收尾轮也计预算
3、无视才截断：收尾后仍发 toolCall → abort 硬截断
4、独立归因：截断后终态标 max_turns（errorCode=MAX_TURNS，非 completed/failed），UI 显「执行异常」类（会话流卡 tooltip 可见分码）
5、usage 口径：面板/卡片的 token 合计 = 子会话**逐轮 message_end 内存累计**（ΣtotalTokens，B1 修），settle 终态落盘同口径——非「末条 assistant message」值。运行期不落盘（2026-11-07 定夺）

## 子代理会话查看

子会话在 PF 打开为普通会话 tab，**复用对话 view，隐藏输入面板**（只读观察窗）：

- 子代理 live 会话住在父 pi 进程内，tab 是对同一账本文件的观察视图（打开快照 + 空闲态外部追加跟随，~3s 延迟）
- 输入面板一律隐藏：用户输入会生成第二驱动分叉账本、双花 token、抢占模型商并发——子代理由主agent独占管理，用户无输入通道
- 变异操作（fork、消息操作栏）随输入面板一并隐藏
- tab 归宿（2026-11-06 定稿）：子会话 = **自由区普通 tab**（PanelTab::Observer，追加 tab 区末尾，标题=descriptor 任务名，× 可关），固定段第一位永远留给主会话/新会话；观察窗不写 last-open，启动恢复过滤子会话（历史污染防护）
