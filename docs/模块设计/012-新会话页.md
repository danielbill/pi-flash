## 额外操作栏
在inputpanel下方，间隔5px
高40px，无边框，宽度对齐 inputpanel；

- 左侧是 打开项目菜单按钮， 内容显示为： 目录图标 + 当前工作项目名， 如果当前没有工作项目，则显示为【选择项目】，点击后进入 004-项目管理 中的 打开项目流程
