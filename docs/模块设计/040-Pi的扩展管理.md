Pi-Flash 中，用「扩展」指代 pi 的 package（settings.json `packages` 条目）。

代码落点：

- 页面与动作：`crates/app/src/settings/pi_extensions/`（`mc_*_package` 动作 + `PkgOp` op 类型 + 页面渲染 `panes.rs`）；安装/卸载/更新都走 `mc_cli_op` 后台线程跑 vendored pi CLI，op 泵收尾清 busy 并刷新列表
- 会话勾选菜单：`crates/app/src/session/pi_extension_picker.rs`
- 说明 token 测量：`crates/app/src/services/token_probe.rs`
- 更新检测与更新动作：`crates/app/src/services/pi_extension_updates.rs`（082）

对应界面：
1. settings - 扩展
2. inputpanel - 扩展按钮/菜单

## settings - 扩展

### 界面功能设计
- 列出全局已安装的全部扩展（settings.json `packages`）
- 组头三态总开关统一开启/关闭所有扩展（部分启用时轨道减淡、knob 停在开位），右侧显示 启用数/安装数
- 单个扩展行内开关启停；垃圾桶卸载（统一确认浮层）
- 安装支持从 https://pi.dev/packages 复制安装命令整条粘贴（如 `pi install npm:pi-web-access`，`normalize_source` 剥前缀）。只支持全局安装。安装中按钮转圈禁用（op 单飞），完成后刷新已装列表

### 界面结构
上方【安装区】，下方左【已安装扩展列表】+ 右【扩展详情】两栏。

### 安装区
提示行（`https://pi.dev/packages` 为可点击链接，打开浏览器 + 「复制安装命令」说明）在输入框下方；输入框宽 400px + 安装按钮一行。安装出错时错误行紧随其下。

### 已安装扩展列表
左栏宽 `widgets::LIST_W`（450，与模型/技能/MCP/子代理页共享）。

首行 title【配置全局默认扩展】，右侧【更新全部(n)】按钮（082，无可更新或 op 进行中禁用、更新中显示「更新中…」）+ 启用数/安装数 + 总开关。

下方列表：左侧包名（`display_source`，去掉 `npm:` 前缀），右侧启停开关；有可用更新的包在名称右侧加 ↑（082）。列表超限出滚动条。

启停语义是**全局**的：往 settings.json 里把该扩展写成
`{source, extensions:[], skills:[], prompts:[], themes:[]}`（pi 认这个「资源置空」
过滤），恢复为字符串条目 = 启用。它改不了单个会话。

### 扩展详情

第一行：[全局] 标识 + package 名称（去掉 `npm:`）+【更新】按钮（082，仅该包检测为「有可用更新」或正在更新时显示）+ 垃圾箱 icon（本包卸载中转圈，任一 op 进行中禁用）。启停不在详情页，统一在左列表的行内开关。

下方字段行（标签在上、内容在下）：
- 说明：来自包内 package.json 的 description
- 状态：启用|停用
- 说明大小：xxx tokens（延迟加载测得；未测得显示「—」）
- 来源
- 路径（长路径自动折行）

## inputpanel 的 扩展按钮
工具胶囊右侧 `plug` 按钮，仅「自定义（full+）」档激活（其余档扩展不挂载，点击提示）。

菜单打开时：当前会话清单自动勾选并置顶（新会话创建时从全局启用集复制为初始清单），其余按展示名排序；去掉 `npm:` 前缀；项目级包带「项目」小标；每行右侧标注说明 token 数（测得才显示）；头部显示当前勾选集的 token 合计。按钮计数【(n)】实时反映勾选数。

### 每轮对话都可调整
勾选即生效（无确认按钮）：每勾/取消一项当即写入 `runtime.ext_sources` 并落
`~/.pi-flash/session-ext.json`（每个对话一份，重启恢复）。重绑统一走
`pending_ext_sources`：下一轮 `send_input` 空闲发送前重绑进程（`--session` 复接
不丢消息）——连点 N 项只重绑一次，运行中不掐轮（pi 的 RPC 没有运行时换包命令，
重绑是唯一通路）。

046 任务页嵌入态：勾选写任务表单 `tasks.page.extensions`（随【保存】进任务
spec，派发时按它挂载），不碰背后会话。

## 扩展说明占多少 Token 预览
扩展包可能占大量系统上下文。测量在启动揭幕后的**延迟加载**阶段后台进行
（`token_probe.rs` 两段式：静态探针复用 pi 扩展装载器测装载期可见三块，
懒注册包再经单会话精确测量补齐），结果缓存 `~/.pi-flash/ext-tokens.json`。
非关键过程不占启动链路。

预览两处：
- settings - 扩展 - 详情【说明大小】行
- inputpanel 扩展菜单：行右侧 token 数 + 头部【合计】（面板加宽到 420 容纳）
