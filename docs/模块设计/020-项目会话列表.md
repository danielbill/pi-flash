## 伪标签（draft 已发送、pi 未落盘的占位行）

侧栏的会话标签 = 磁盘扫描（`refresh_sessions`），而 pi 的会话文件要等首条
user/assistant 消息才落盘（session-manager `_hasConversation`，#10000），
新会话冷启还要等 node 进程 boot（1-3s）——没有伪标签时，「发送消息 → 侧栏
出现新标签」之间有一段无反馈空窗。

- **挂**：`optimistic_send`（prompt/steer/微信远程共用漏斗）发现 runtime
  还是 draft（`file.is_none()`）→ emit `SessionEvent::PendingTab(Some(首行
  预览))` → Chat 的 `pending_tabs` 插入占位行。发送的同一帧上侧栏：样式与
  真标签同款（行高/字号/选中色），左侧状态槽 = spinner，标题 = 消息首行
  （真标签落地后的 preview 与它一致，衔接无跳变）。位置 = 归属项目组会话
  行最前（Flat 模式列表最前；组还不存在则 Title 后置顶）。折叠组里照常
  显示；无 hover 卡（rename/delete 依赖真实文件）。
- **换真身**：首条用户消息事件到达时 runtime 调 `try_bind_reported_file`
  ——pi 报备过的 sessionFile 此刻已在盘上（先 appendMessage 再发事件），
  `follow_session_file` 的存在性守卫放行 → FileBound → `on_file_bound`
  迁移 pool key（draft-N → 路径）并摘掉伪标签，磁盘扫描的真标签接管。
  不等 AgentSettled 才绑定：否则「真标签已上侧栏、pool key 还是 draft-N」
  的窗口里点标签会 spawn 出 duplicate runtime。
- **撤**：三个确定「永远不会有文件」的时刻撤标签——prompt 被 preflight
  拒绝（无鉴权/无模型）、AgentSettled 时报备文件仍未落盘（prompt 被扩展
  接管，pi 没写过任何消息）、进程退出且未落盘。判定统一走
  `try_bind_reported_file`（绑定在途时返回 true 不误撤，避免闪烁）。
- **幻影绑定守卫**（伪标签的前置）：pi 在 SessionManager 构造期就把
  sessionFile 定死，启动期 get_state 带回的是还不存在的路径——
  `follow_session_file` 对 `!f.is_file()` 直接不绑定，boot 草稿保持
  draft 身份。副产品（改善）：「开了 app 没说话就关」不再用幻影路径覆盖
  last_open，下次启动恢复上一个真实会话。
- 伪标签是纯内存态：没落盘的 draft 重启后本就不存在，无需持久化。

## project标签增加拖动功能
首先是默认排序，app打开时，按最后活动先后顺序排序不变，但仅做一次。
后续用户切换会话时，不再自动置顶。

用户现在可以通过拖动project标签，将关注的项目排到任何位置。
鼠标现在hover project标签时，切换为系统手型指针。

项目拖拽时收起为标签。
拖拽结束后，项目会话列表的排列顺序自动持久化，下次打开依旧如此。

app再打开时，如果有用户排序记录，项目排列顺序则不再使用最后活动时间排序，使用用户排序。
当然，项目内会话依旧使用活动顺序排序。

### 置顶实现要点

- **状态与持久化**：`psp.session_pins: Vec<PathBuf>`（index 0 = 最近置顶，
  「后置顶的总在最上面」直接由插入位保证）；落盘 = `UiState.session_pins`
  （workspace 记忆文件 `__ui` 键），pin/unpin 即刻 `persist_ui`（不等关窗）。
  唯一写路 `Chat::session_pin_toggle`（自动化 op `session.pin` 同槽），删除
  会话/项目两路同步清册。
- **行模型**：`PspRow::PinnedHeader`（伪项目头行，零交互：不收折/不拖拽/
  无右键卡）+ `PspRow::PinnedSession{p,s}`（原组下标引用）。行元素 id 用
  `ps-pin-{id}` 前缀（防御性保留）。置顶组行不参与项目块避让平移（block=None）。
- **Grouped（移入语义，zcode parity）**：置顶会话只在置顶组出现，原项目组按 pin 清单过滤
  （`visible` = 未置顶的下标集），不再重复显示；分页计数用 `visible.len()`
  （否则置顶几条后原组只剩「显示更多」的死行）。恒在最顶（含当前项目之上）；
  组内按 pin 序；清单外（已删/未装载）的置顶项静默跳过，全空则整组不渲染
  （需求 ⑤）。
- **Flat**：伪标签（最新活动）仍在最前，其后置顶会话按 pin 序排会话区
  第一位（稳定排序，非置顶项相对序不变），置顶项同样吃「显示更多」分页
  ——Flat 本就是单份列表，天然无重复。
- **pin 槽位（需求 ①）**：状态槽 15px 与 pin **互斥渲染**。**任何行都不常显 pin**；**只在悬停时**出现
  置顶钮，图标随置顶态翻转——未置顶 = `pin`（置顶）、已置顶 = `pin-off`
  （取消置顶）；MD 档中性色，不用主题色不抢注意力。pin 钮只在可见时
  存在（tracked hover 态 `psp.hovered_session` 门控，与 hovered_project
  同款翻转才 notify）——不可见的钮不拦截点击。点击 `stop_propagation`，
  不触发开行。
- **右键卡（需求 ②）**：会话卡动作栏 pin 钮在最左（贴卡内左缘），删除/
  确认组仍右对齐（flex_1 占位）；点击只 toggle 不收卡，tip 文案随置顶态
  翻转（置顶/取消置顶）。
- **窗口外置顶会话可见性**：置顶的意义就是老会话常驻可见，两处并集——
  启动装载（`spawn_boot_restore`）把 pin 路径追加进 recents 窗口清单
  （追加在尾部，不挤占 tail 预载名额）；`refresh_sessions` 对当前项目的
  置顶会话做 active 同款兑底（窗口外也保留）。

### 实现要点

- **排序三分支**（`rebuild_projects`，按序命中）：
  1. `psp.proj_order`（用户排序，组 ws_key 有序表）存在 → 永远按它排；未收录的新项目按活动倒序垫底；
  2. 无用户排序且首建（`projects` 为空）→ 默认序只排这一次：当前项目钉顶 + 活动倒序。此后运行期重建走保序——**切换会话不再自动置顶**；
  3. 其余运行期重建 → 保序，新出现的组按活动倒序追加尾部。
  组内会话恒按活动倒序（构建期显式 sort，不依赖扫描序）。
- **持久化**：`UiState.proj_order`（workspace 记忆文件 `__ui` 键，空表 = 无用户排序）；拖拽落位即写（`commit_drop` → `persist_ui`）。
- **拖拽**（`function_panel/psp_drag.rs`，Zed project_panel 三件套同款）：
  - `on_drag` 发起（载荷 = 组 ws_key），幽灵 = folder+名字小签——「拖拽时收起为标签」的可见形态；组体的会话行在 `psp_rows` 渲染期折叠（不碰 `collapsed_keys`，拖完自动还原）；
  - 行侧 `on_drag_move` 半行判定插入位（上/下半 = 插本行前/后；拖回自己或相邻 = no-op，空槽闭合不落位）；容器（psp-scroll）`on_drag_move` 做状态同步漏斗（区内续期 / 拖出列表区清态），`on_drop` 兜底提交。
- **视觉规格（ZCode 侧栏 dnd-kit parity）**：
  - **幽灵** = 全行宽（slp_w−2×LIST_PX）× 32 高的项目行小卡（border + shadow_lg）。gpui 以 min-content 约束布局拖拽幽灵，不显式定宽就塌缩成内容宽；锁 x：渲染期按 `mouse.x − 起手 mouse.x` 反向补偿 `.left()`，chip 只纵向跟随（ZCode restrictVerticalDragWithinContainer 同款）；gpui 幽灵定位 = `mouse − cursor_offset`，天然保留抓取点偏移。
  - **源行 opacity 0**（保留 32px 槽位）——避免「列表里一个头 + 浮动 chip 一个头」；展开的组体照旧渲染期折叠。
  - **避让动效**：活跃块与落点之间的项目**整块**（头行+会话行）平移一行高（32px），`ProjShift{from,to,start}` 按 elapsed 200ms ease_in_out 插值，16ms ticker 驱动重绘（ctx_tip 惯例）；行用 `.relative().top(位移)` 只动视觉不动布局，空槽即落点指示（无指示线）。块归属：行序列里 Project 之后的一切行归属该块，孤儿伪标签不平移。
- **取消清理**：gpui 对「列表外松手」不派发事件——拖出列表区由容器 drag_move 的 contains=false 实时清态；出窗后松手（再无事件）由看门狗按 `at` staleness（700ms 无续期）兜底清态。
- **与折叠点击的互斥**：项目行折叠切换挂 `on_click`（mouse-up）——gpui 拖拽激活（位移超阈值）会吞掉 click，按下即翻转会在拖拽起手时误折叠。
