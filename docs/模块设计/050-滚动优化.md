# 050 滚动优化

会话区（及所有 gpui List / 编辑器）的滚动手感与滚动性能设计。

模块代码：`vendor/gpui/src/elements/list.rs`（List 滚轮路径）、
`text_system/line_layout.rs`（排版缓存层）、`session/chat_list.rs`
（钉顶状态机，见 032）、`vendor/gpui-component/src/input/`（文件编辑器路径）。

## 零、滚轮：原生直滚（Zed parity，勿再加动画）

Zed 全仓没有滚轮平滑动画：编辑器滚轮在 `crates/editor/src/element/mouse.rs`
收到 delta 后直接改 scroll 位置（换算成小数行 `ScrollPixelOffset`）再
`editor.scroll()`；gpui 的 `List` / `div().overflow_scroll()` 同样把 delta
直加到滚动位。**「丝滑」来自帧时间 ≤ 一帧，不是缓动。**

本项目 v61 曾自造过两版滚轮动画（指数逼近 → AOSP `SplineOverScroller` 闭式
样条，都在 `elements/list.rs`），**已全部撤销**：与 Zed 行为不一致，而且在
debug 构建下（每帧 50ms+）无论怎么调参都不丝滑——动画只是把掉帧摊开。
手感问题请改帧时间，不要再往滚轮上加动画。

验收口径：**用 `target/release/pi-flash.exe` 判手感**（release 才是 Zed 那一档），
dev 构建只用于迭代。一帧预算 16.7ms，用 `ZED_MEASUREMENTS=1` 的
`frame duration` / `Get-Process pi-flash .CPU` 量。

## 一、性能层：三缓存

### 1. LineLayoutCache 存档层（text_system/line_layout.rs）

- 问题：两帧滑动窗口 → 滚动重进条目 = 数百行重新 shape（大 markdown 轮块
  单帧 5-30ms）。最新 Zed 也是两帧设计（编辑器靠自有 wrap map 不受害）。
- 方案：新增 `archive: ArchiveCache`（48MB 字节预算、插入序驱逐）。
  `finish_frame` 把掉出两帧窗口的布局**沉降**入档而非丢弃；查找路径
  current → previous → archive 三级回退，命中搬回 current（预算内重新沉降
  时自然刷新插入位，近似 LRU）。
- 字节估算 16B/字符 + 512B 常数；重复沉降覆盖不重复记账，order 陈旧 key
  驱逐时跳过（total_bytes 在查找搬回时已扣减，无下溢）。

### 2. markdown 解析缓存（app/markdown.rs `cached_blocks`）

- 问题：List 每帧对可见条目重建元素树，pulldown-cmark 每帧白打（大消息
  数百 µs～ms）。
- 方案：key =（FNV-1a 8 字节块哈希, 源文长度, html 标志），命中后**全等
  校验**防碰撞；线程局部 VecDeque 128 项 LRU，值 Rc<Vec<MdBlock>> 渲染期
  零拷贝。流式末条每 delta 一变 → 命不中也只是队头轮换，不影响他条命中。
- 只缓存解析（src+html 决定），不缓存渲染（streaming/theme/字体每帧可变）。

### 3. 图片解码缓存（app/session/messages.rs `decode_image_cached`）

- 问题：base64 图每帧重走解码 + `Image::from_bytes` 内容哈希（几百 KB =
  ms 级）。
- 方案：key =（哈希, 长度, ImageFormat），64 项 LRU；**Err 同样入缓存**
  （坏数据不反复重试）；`Image.bytes` 公开字段保住 MAX_IMAGE_BYTES 校验。

## 二、编辑器路径（大文件）的每帧成本

`vendor/gpui-component` 的 CodeEditor 每帧只建可视行，但历史上三处是
O(首行行号)/帧或 O(文档)/帧——已改为闭式（`soft_wrap(false)` 时行高恒定）：

- `calculate_visible_range`：可见首行 = `(-scroll_top)/行高`（Zed PositionMap
  同款闭式），不再从第 0 行累加行高；
- `layout_cursor`：光标/选区 y = 行号 × 行高，不再从第 0 行扫到光标；
- `scroll_to` / `offset_to_display_point` / `display_point_to_offset`：同款闭式；
- 打开大文件：`text` 语言不再建 tree-sitter parser（Zed：无语言 = 无语法树）、
  不软换行时不再逐行 materialize 行文本。

实测（2026-10-08，4.6MB / 80k 行 txt）：打开冻结 8.7s → 4.3s(dev) / 0.6s(release)；
逐页翻帧时间 dev 54-64ms → **release 12ms 均 / 20ms 峰（≈80fps）**，
深浅页同量级（O(滚动深度) 已消除）。
