模块代码：sessionStatusBar 034

会话内容列最底部一条常驻状态带：承载 pi 扩展 `ctx.ui.setStatus(key, text)`
申请的状态项，“可点项”点击=执行命令，如发送 /usage 

## 1. 定义

- **状态项**（item）= `{ key, text, action }`。key 由扩展命名，text 为扩展自由
  文本；action 由 PF 侧动作表把 key 映射出来（`RunCommand` / `OpenPanel` / `None`）。
- **扩展槽** = 状态项横排区（本文主体）；**会话槽** = 左端预留，本期空。
- 不是会话内容（不随消息滚动）、不是 composer 用量环/`ctx_tip`（031）、不是左
  dock 控制条（018 `status_bar.rs`，勿混名）、不是 toast、不是排队条（031 状态槽）。

## 2. 显示开关

Inputpanel 功能栏上，MCP 按钮右侧，图标 lucide `badge-info` + 开关，**默认开启**。
防信息冗余用；关闭只影响渲染，数据面照旧。

| 项 | 规格 |
|---|---|
| 形态 | icon `badge-info` **ICON_SM 14**（开 `text_muted` / 关 `text_faint`）+ SP3 gap + **SW_SM 24×14** |
| 实现 | `ui/kit/switch.rs::switch_base_sm`（紧凑档；kit 已有两档，禁手搓） |
| 命中区 | 整块 `px 6`、`h 28`，与同排 MCP 胶囊等高 |
| 提示 | `footerbar.tip.toggle`「显示扩展状态栏」 |
| 落盘 | `ui_state().session_status_bar: Option<bool>`，缺省 = 开（不进设置页） |
| 生效 | 状态直切无动画、无 toast |
| 资产 | `crates/app/assets/icons/badge-info.svg` 需新增 + `src/assets.rs` 登记 |

## 3. 位置与几何

### 3.1 位置

inputpanel 正下方，**与内容区（消息列）同宽**，高 28px。放在 `chat-wrap` 底缘
的 **absolute 覆盖层**（最后绘制）——不参与 flex 流，因此**开闭之间 Inputpanel
不动**（胶囊永久上移 8px）。**新会话页（012）不显示。**

垂直几何联动（三处必须一起改，漏一处就会压消息/错位）：

| 量 | 落点 | 原值 → 新值 |
|---|---|---|
| 胶囊底距 | `session/input/area.rs` `composer_wrap` | 20 → **28**（= `footer_bar::BAR_H`，**永久值**；条是 absolute 覆盖层，开关不改变布局，胶囊永不动） |
| 悬浮让位 | `session/chat_list.rs` `PAD_BOTTOM` | 180 → **188**（胶囊上移 8 的补偿；同时覆盖条自身 28px，消息不会压在带子下） |
| Inputpanel 高度 −5 | `area.rs` 操作栏到下边框 `pb` | 12 → **7**（压缩胶囊内部留白；会让实测 `composer_h` −5，033 竖条中心随之 −2.5，预期内） |

### 3.2 尺寸与配色（全取 UI组件规范令牌，禁手搓）

### 3.3 横向分区

```
[        项 | 项 | 项（内容列内居中）        ]
```

- 项在内容列内居中（用户定夺，2026-11-04）：右侧 composer 已有模型/思考两行信息，
  状态带再右对齐会形成两条贴右的竖排文字。会话槽（原先的 `flex_1` 左撑）随之取消
  —— 会话态信息仍归 composer 用量环与 022 git 面板，不在此重复。
- **多条信息用 ` | ` 分隔**（用户定夺，2026-11-04）：淡色分隔符（`text_faint`），
  与两侧项各留 SP2 = 4，项间不再用固定 gap。

### 3.4 显隐（全部零占位）

新会话页 / 无活动会话 / 开关关 / 非空项全被逐键静音 → 整条不渲染（不建
element，不占 28px）。

## 4. 内容模型与准入

- **数据面**：`SessionRuntime::ext_status: Vec<(String, String)>`（`dialogs/ext_ui.rs`
  的 `SetStatus` 分支写入，含 ANSI 剥离）。**per-runtime 而非 Chat 级**：pi 换会话/
  重载会清扩展状态，池里每个 pi 进程各持一份，放 Chat 上会串味。
- 排序：**key 字母序**（pi footer 同口径）。同 key 重复写原地替换；`text` 空 → 摘除。
- **准入 = 默认全显示 − 用户逐键静音**（2026-11-04 定案 B，替代此前的白名单）：
  扩展状态项全部上屏（Pi 老用户默认需求），动作表只决定**可不可点**、不管显示。
  想藏某一行是个体偏好 → `ui_state.ext_status_muted: Vec<String>`（workspace.json
  的 `__ui.ext_status_muted`，如 `["mcp"]`）；数据面照旧收全量，只是渲染跳过。
  静音入口后续做"隐藏这一行"时接上（`set_ext_status_muted_keys` 已备）。

| key | 动作 | 上屏 | 说明 |
|---|---|---|---|
| `usage` | `RunCommand("/usage")` | ✅ 可点 | 与手打同一漏斗，见 §5.1 |
| `mcp` | — | 默认上屏（灰字纯文本） | 本机用户偏好静音（workspace.json 已写 `["mcp"]`）；composer 功能栏已有 MCP 胶囊做主入口 |
| `mcp-auth` / `freeflow` / `goal` / `cline-login` / 其他 | — | 默认上屏（灰字纯文本） | 无动作 = 纯文本，不可点；要给某键加动作改 `action_of` + 本节 + 模块注释 |

## 4.3 过载处理（内容管理，用户定夺 2026-11-04）

0. 多条信息用 `|` 分隔（淡色 `text_faint`，两侧 SP2 = 4）。
1. **单行 + 截断**：可用宽 = 内容区宽度 − 20px（两侧 px10）；项挂
   `min_w_0 + overflow_hidden + whitespace_nowrap + text_ellipsis` —— flex 挤压
   各项、尾部 `…`，**禁止折行**毁 28px 条；条本体 `overflow_hidden` 兜底。
2. **`[...]` 管理入口**：状态栏右侧、贴内容列右缘（约对齐 Inputpanel 发送钮）。
   图标 = lucide ellipsis（裸三点，全库唯一「更多」），ICON_SM 14 / `text_faint`。
   点击弹出菜单：**宽 200px、最小高 200px**（`ui::menu::menu_card`，PopupEdges
   around 点击点），内容 = 申请常驻状态栏的插件键清单（当前会话键 ∪ 已静音键，
   字母序），勾选 = 上屏、取消勾选 = 隐藏（写 `ext_status_muted`，菜单保持打开、
   实时生效）。全部静音时状态带只剩 `[...]`（唯一找回入口）。
   快照不变：`hidden_keys` = 静音键留痕。

## 5. 交互

### 5.1 点击 = 命令路径

`RunCommand("/usage")` 走 `SessionRuntime::optimistic_send(text, pin, cx)`（手打
`/usage` 的同一漏斗）：命令相位 + `handled` 收场 + 乐观气泡 + 磁盘真相收场 +
运行中排队，全部复用。不新写发送逻辑，不自己画面板（pi-usage 的 `/usage` 本身是
`ctx.ui.select` 菜单链，PF 里就是那串 ext Select 卡）。

### 5.2 三态

| 状态 | 视觉 | 行为 |
|---|---|---|
| 可点且可用 | `cursor_pointer` + hover `bg_hover` + `text_muted` | 左键触发动作 |
| 可点但禁用（运行中） | `opacity 0.5`，无 hover/pointer | 无响应 |
| 无动作键 | `text_faint`，无 hover/pointer | 纯文本（可被逐键静音） |

- 点击用 `on_mouse_down(Left)`（与 018 控制条、插件 tab 同款）；命中区 = 项整块
  （含 `px 6 / py 2`），最小高 22；不需要二次确认。

### 5.3 禁用规则

- `RunCommand` 在 `agent_running` 时禁用，tooltip `footerbar.tip.busy`「当前轮次
  结束后可用」（避免排队命令像点了没反应）。
- `OpenPanel` 随时可点（纯 UI 跳转）。

### 5.4 悬停提示（唯一入口 `ui::tooltip::WithTip`）

| 元素 | 提示 | i18n |
|---|---|---|
| 可点项 | `打开用量面板（/usage）` | `footerbar.tip.usage` |
| 禁用项 | `当前轮次结束后可用` | `footerbar.tip.busy` |
| 纯文本项 | 仅被截断时出全文 | `with_tip_text`（不过 i18n） |
| 显示开关 | `显示扩展状态栏` | `footerbar.tip.toggle` |

### 5.5 不做

键盘焦点体系（键盘用户走 `/usage`，tooltip 注明等价命令）；右键菜单、拖拽排序、
双击、长按；点击改扩展内部状态；自动展开面板/悬浮预览（与 `ctx_tip` 打架）。

## 6. 数据与生命周期

1. **per-session**：只显示当前活动会话的项；切 tab / 切池按新会话重算，不跨会话
   合并、不做旧值兜底。
2. **清空**：pi 在 `resetExtensionUI()` 里 `clearExtensionStatuses()`；PF 对应口径 =
   **`spawn_attached` 时清**（新 pi 进程 → 旧 setStatus 快照作废；覆盖 `/reload`
   重绑与空闲回收重建）。切会话不需要额外清——数据随 runtime 走，天然不串味。
3. **零重算**：动作表静态 match、键序稳定、不做格式化；`SetStatus` 到达已
   `cx.notify()`，天然一帧一次。
4. **热路径**：纯文本 + flex，无测量循环/图片/阴影；不渲染时零成本。
5. **快照**：`automation/snapshot.rs` 增 `session.status_bar`
   `{enabled, visible, items:[{key,text,action,disabled}]}`；`session.ext_status` 保留。
