# 90-3 插件系统 UI 组件规范

> 2026-12 / **v2 2026-10-23** / **v2.1**（`grid`，§2.4）/ **v2.2**（`panel-frame`，§2.6）。
> **插件不绘制任何像素**：插件返回**已算好的组件树**
> （值内联、动作显式），宿主是树解释器。本文件是 UI 契约的散文版，
> **机器真源 = `schema/plugin-contract.json`**；两者冲突以 JSON 为准并立即改本文。
> v1 的「数据源 / `$字段` / `$auto` / `rows`」整层已删除，见 §6。
> **布局裁决权归宿主**：插件只声明结构与档位，尺寸/列数/换行/DPI 由宿主定；
> 宿主**不得**按插件类型或组件组合去猜布局（“连续 `button` 就摊成格子”是禁止的）。
>
> 上位规范：`docs/UI设计/UI组件规范.md`（下文简称**主库规范**）。
> 本文件不重复其数值，**一切尺寸/颜色/字号/圆角均引用主库变量名**，
> 禁止在本文或插件包里出现字面量。

## 0. 定位与边界

| 归属 | 内容 |
|---|---|
| **插件声明** | 组件树结构、文案、内联的值、动作、图标引用 |
| **宿主渲染** | 布局、滚动、焦点、hover、右键菜单、主题色、密度、DPI |
| **宿主执行** | 动作（打开文件、跑脚本、开链接…），插件拿不到执行权 |

三条铁律：

1. **零数值**：插件侧不出现 `px` / 色值 / 字号 / 圆角数值。只写 token 名（§7）。
2. **零绘制**：插件不产 display list、不调 gpui、不含 UI 代码。
3. **零字段解析**（v2）：插件返回的树里**值已内联**——宿主不认字段名、不做过滤、
   不折算动作。数据从哪来、怎么算，全在插件里（存储见 90-4 §3）。

## 1. 组件词表（v2 封闭清单）

**封闭**：不在本表的组件，`check` 直接报错；宿主渲染到未知组件置为占位块并记录日志。

| 组件 | 用途 | 对应宿主实现 |
|---|---|---|
| `panel-frame` | **面板外壳**：分区 + 各自滚动 + 可拖拽分隔线（宿主画） | 与 project panel 同款骨架 |
| `section` | 一个分区（只能出现在 `panel-frame` 内） | 分区标题 + 内容 |
| `column` | 纵向容器（内容区内部用） | `div().flex_col()` + kit 间距 |
| `row` | 横向容器 | `div().flex_row()` |
| `group` | 分组标题 + 内容 | 主库规范 §5.8 分组标题 |
| `grid` | 等宽格子流（通用） | 宿主按面板宽度算列数后铺 equal-width 网格 |
| `divider` | 分隔线 | 主库规范 §5.8 分隔 |
| `text` | 文本 | kit `row` 文本块（主库规范 §10.3） |
| `icon` | 图标 | `ui::icon` / `icon_path`（§3.3 三来源） |
| `button` | 按钮；列表格/行也用它 | kit `button`（主库规范 §5.1） |
| `switch`（v3） | 开/关开关 | 宿主统一开关样式；点击翻转 → `onCommand(command,{value:新布尔})` |

**v3 后仍不在**：`list` / `input` / `checkbox` / `slider` / `tree` / `badge` /
`tooltip` / `image`（图形走 `canvas` 直画）/ `spacer` / `webview` / 任意自绘容器。
加组件 = 改宿主 + 升 `engines.pf`。
`list` 只在行数上千、需要虚拟滚动时才值得引回，那时按契约版本升级办理。

## 2. 结构组件

### 2.1 `column`

```jsonc
{ "type": "column", "gap": "SP3", "pad": "SP4", "children": [ /* … */ ] }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `gap` | token `space.*` | 子项间距 |
| `pad` | token `space.*` | 内边距 |
| `align` | `start` / `center` / `end` / `stretch` | 交叉轴对齐，默认 `stretch` |
| `justify` | `start` / `center` / `end` / `between` | 主轴（纵向）对齐，默认 `start`；空态提示整块居中用 `center` |
| `children` | 组件数组 | — |

> `column` **没有** `scroll`：滚动只发生在 `panel-frame` 的 `section` 里（§2.6）。
> 需要一整块可滚动 → 用 `panel-frame` + 一个 `section`。

### 2.2 `row`

属性同 `column`，语义为横向；`align` 指纵向对齐，`justify` 为 `start/center/end/between`。

### 2.3 `group`

分组标题 + 内容，标题样式固定走主库规范 §5.8，插件不得改字号/颜色。

```jsonc
{ "type": "group", "title": { "zh": "可执行文件", "en": "Executables" },
  "children": [ /* … */ ] }
```

### 2.4 `grid`

**等宽格子流**：每个 child 占一格。这是通用原语（快捷方式、图片墙、模板选择同类），
宿主里没有任何插件语义。

```jsonc
{ "type": "grid", "minItem": "SM", "children": [ /* 每项一格 */ ] }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `minItem` | `SM` / `MD` / `LG` | **建议**最小格宽档位，宿主映射到实现值（88/120/160px），插件不写数值 |
| `children` | 组件数组 | 每项占一格；**不得嵌套 `grid`** |

**谁决定什么**：

| 归属 | 内容 |
|---|---|
| 插件 | 这是格子流 + 建议档位 + 每格内容（图标/文案/动作） |
| 宿主 | 列数 `clamp(floor(可用宽 / 档位宽), 1, 6)`、格宽撑满列、换行、标签省略、DPI |

格子等宽、可随面板变宽而变宽（标签占满列宽 → 名字显示更多）；宽度上限由列数公式兜住，
不会出现“一行一个巨格”。

> **禁止**：宿主不得从“`column` 里连续放了几个 `button`”之类形态猜出格子布局。
> 想要格子就显式写 `grid`——这一条是契约级的，见 `schema/plugin-contract.json`
> 的 `layout_ownership`。

### 2.5 `divider`

```jsonc
{ "type": "divider" }
```

`divider` 纵向留白取主库规范 §5.8；颜色统一用 `text` 的低透明度发丝线
（`border` 在暗色主题下与底色过近，看不清）。v2 无 `spacer`（横向留白用 `row.justify`）。

### 2.6 `panel-frame`（面板外壳，宿主画）

**视觉一致性由宿主保证**：分区标题样式、每个分区各自滚动、中间分隔线可上下拖拽、
内边距、滚动条——全部与 project panel 同款。插件不再用 `column`/`divider` 手拼外壳。

```jsonc
{ "type": "panel-frame", "children": [
    { "type": "section", "title": { "zh": "程序" }, "icon": "play", "children": [ /* 内容 */ ] },
    { "type": "section", "title": { "zh": "文档" }, "icon": "assets:doc.svg", "children": [ /* 内容 */ ] } ] }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `children` | 1..4 个 `section` | 1 个 = 不分区（整块滚动）；多个 = 上下分区 |
| `section.title` | 文案对象（可省） | 文案插件给，样式宿主定 |
| `section.icon` | 图标引用（可省） | 内置名（如 `play`）或 `assets:doc.svg`，与 `button.icon` 同规则 |

**分工：插件给意图，宿主算像素**（这是全契约的通用口径，不针对某个面板）：

| 谁定 | 定什么 |
|---|---|
| 插件 | `titleAlign`（`start` / `end`）、`titlePad`（**SP token**，如 `SP8`） |
| 宿主 | token→px、DPI 缩放、标题字号/字重/图标档、以及缺省值兜底 |

宿主固定部分：外壳留白 `PANEL_PAD`（=12px，与 topbar 工具条图标边距同值）、
标题上方 8px、图标 **MD=16px** + 6px 间距 + **body=ui(12) semibold** 文字、
标题色 **`text.faint`**。

> **分区标题是次要信息**（用户定夺）：颜色必须比内容淡，不许抢视觉。
> 也因为淡、且靠左，缩进要比内容再进一档（示例用 `titlePad: "SP8"` = 20px），
> 否则像贴在墙上的标签。
`titlePad` 比外壳留白大就补差额，小则不外扩（不出现负 padding）。

**插件仍然不得写像素数**：`titlePad` 是 token 名，不是 `20`。

| 归属 | 内容 |
|---|---|
| 插件 | 分几个区、每区标题、每区内容（内部再用 `column`/`grid`/`button`…） |
| 宿主 | 外壳布局、分区标题样式、各自滚动与滚动条、分隔线拖拽、各区间比例、内边距 |

分区比例是**宿主 UI 状态**（内存态，重启回等分），**不写进插件数据**。

**禁止**：插件用 `column` + `divider` 手工拼出“看起来像分区”的东西（那会立刻与
project panel 不一致）；要分区就用 `panel-frame`。

### 2.7 `section`（分区）

只允许作为 `panel-frame` 的直接子项；`children` 为该区内容。出现在别处 = `check` 报错。
`title` / `icon` 都可省（省掉则只画内容，不画标题行）。

## 3. 内容原子

### 3.1 `text`

```jsonc
{ "type": "text", "value": { "zh": "…", "en": "…" }, "tone": "muted", "size": "SM" }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `value` | 文案对象（`zh` 必填）或纯字符串 | — |
| `tone` | `text` / `text.muted` / `text.dim` / `text.soft` / `text.faint` / `accent` / `danger` | **theme 字段名**，禁色值 |
| `size` | `XS` / `SM` / `MD` / `LG` | 主库规范 §2 字号档 |
| `weight` | `regular` / `medium` / `semibold` | 字重档 |
| `ellipsis` | `bool` | 超宽省略（默认 `true`） |

### 3.2 `icon`

```jsonc
{ "type": "icon", "name": "file-text", "size": "SM", "tone": "text.muted" }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `name` | 见 §3.3 三种来源 | — |
| `size` | `INDICATOR` / `XS` / `SM` / `MD` / `LG` | 主库规范 §3 五档 |
| `tone` | 同 `text.tone` | 宿主据此给 SVG 上色 |

### 3.3 图标来源（三种，互斥）

| 写法 | 来源 | 用法 |
|---|---|---|
| `"name": "<宿主名>"` | 宿主内置（`assets/icons/*.svg`，当前 229 个） | 通用 UI 图标 |
| `"name": "file"` | 宿主按后缀自动判定（`services::file_icons`） | 列表行 / 文件相关处 |
| `"name": "assets:<文件名>"` | **插件包自带** `assets/` 下的 SVG | 插件专属图标 |

```jsonc
{ "type": "icon", "name": "assets:gitee.svg" }
{ "type": "icon", "name": "file" }   // 宿主决定：.ps1→终端图标，.md→文档图标
```

**插件自带图标规范（硬性）**：

1. **单色 SVG**：路径只用 `fill="currentColor"` 或不写 fill；**禁** `#hex` / `rgb()` /
   渐变 / 多色 —— 宿主统一 `text_color` 上色，多色图标会在暗色主题下失效；
2. `viewBox="0 0 24 24"`，24 栅格对齐，无内边距留白；
3. 单文件 < 8KB，禁 `<image>` / 位图 / 字体 / 外部引用；
4. 文件名小写 kebab-case，`assets/` 下平铺（不建子目录）；
5. 引用写 `assets:<文件名>`，扩展名 `.svg` 可省。

**宿主名清单**：宿主随包导出 `icons.json`（`{ "icons": ["arrow-down", …] }`），
包校验器（check）拉这份清单校验 `name`；清单外的宿主名报错（U4）。
插件包内不需要也不允许内联该清单。

**`file` / `ctx.fileIcon()` 的解析规则（file_icon 来源规则表，beads nfx ③）**：

| 文件形态 | 图标来源 | 说明 |
|---|---|---|
| `.exe` / `.lnk` | 系统图标提取 | 目标态：取真实文件图标引用；v1 现状 = 后缀表兑底，系统提取待接（宿主侧缺口） |
| 其余后缀 | `services::file_icons` 后缀表 | `.ps1`→终端、`.md`→文档…（Zed file_icons 同表） |
| 判定不到 | 通用文件图标 `file` | 兑底，不报错 |

解析结果对插件是**不透明引用**：`onMenu` 递来的 `fileIcon`、`ctx.fileIcon()` 的返回值，
插件**只透传**（直接放进 `button.icon`），不解释、不拆解、不自己拼 `icons/…` 路径
（02 规范 §3 同款语义）；渲染时由宿主按引用还原图标。

### 3.5 图标与文字的排布（宿主固定，插件不可指定）

| 场景 | 规则 |
|---|---|
| 列表格/行图标 | 图标 + `SP3` 间距 + 文本，垂直居中；尺寸 `SM` |
| `button` 带图标 | 图标在文本前，间距 `SP2`；纯图标按钮用 `variant: "icon"` |
| `group` 标题图标 | 尺寸 `XS`，`tone`: `text.muted` |
| 图标与文本基线 | 宿主按字体 ascent 对齐，插件不得用 `column`/`row` 手工摆位 |

图标的 `size` 经 `appearance::ui_size` 随用户字号缩放，插件写的档位是**相对档**，
不是绝对像素。


## 4. 交互组件

### 4.1 `button`

```jsonc
{ "type": "button", "label": { "zh": "新建会话", "en": "New Session" },
  "icon": "plus", "variant": "text", "action": "new_session" }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `label` | 文案对象 **或** 纯字符串 | 文案对象 `zh` 必填；数据文案（如文件名）直接给字符串 |
| `icon` | 图标引用（可选） | §3.3；`ctx.fileIcon()` 的返回值原样放这里 |
| `variant` | `text` / `icon` | 主库规范 §5.1 / §5.2 |
| `size` | `SM` / `MD` / `LG` | 主库规范 §5.1 三档 |
| `tip` | 字符串 | hover 提示（如全路径） |
| `action` | §8 动作名 | **宿主执行**，插件无回调 |
| `arg` | 动作参数 | 见 §8 |
| `menu` | 菜单项数组 | 右键菜单，见 §4.2 |
| `disabled` | `bool` | 插件自己算；宿主只画禁用态 |

按钮不定义颜色：默认色、hover、按下、禁用四态全由 theme + 主库规范 §6 决定。

### 4.2 右键菜单项（`menu`）

```jsonc
"menu": [
  { "id": "unpin", "title": { "zh": "移除收藏" }, "icon": "trash", "danger": true }
]
```

| 字段 | 取值 | 说明 |
|---|---|---|
| `id` | kebab-case，插件内唯一 | 回调时原样递回 |
| `title` | 文案对象 | — |
| `icon` | 图标引用（可省） | 与 `button.icon` 同规则（内置名或 `assets:`） |
| `danger` | `bool` | 红字 + 红 hover（删除类） |
| `action` / `arg` | §8 动作 | 带 = 宿主执行；不带 = 回调 `ctx.onCommand(id, { path })` |

**样式与文件树右键菜单同源**（同一卡座 `menu_card`、同一行 `menu_item_asset`、
同一浮层 `psp-overlays`）：行高、图标 14px、hover、贴边翻转、ESC/点外关闭全归宿主，
插件只给图标名与危险色标记。**插件不得自绘菜单**。

### 4.3 `switch`（v3）

```jsonc
{ "type": "switch", "value": true, "label": { "zh": "开启/关闭示例服务" },
  "tip": { "zh": "关闭即断开示例服务" }, "command": "toggle-enabled" }
```

| 字段 | 取值 | 说明 |
|---|---|---|
| `value` | **bool** | 当前布尔态（必填） |
| `command` | kebab-case | 必填；点击翻转后宿主回调 `ctx.onCommand(command, { value: 新布尔值 })` |
| `label` / `tip` | 文案对象 | 可省（纯开关） |
| `disabled` | bool | 可省 |

样式（轨道/滑块/动画）全归宿主统一，插件只给态与回环。

## 4A. fn_bar 注册槽（v3）

会话标签**功能栏右侧的注册槽**：每个会话标签一个插件 icon 按钮，宿主统一 fn 样式
（大小/长宽/padding），按注册顺序从右到左排。

- 清单：`[[contributes.fn_bar]]`，唯一字段 `command`（点击回环 `ctx.onCommand`）
- 插件导出 **`fn_bar(ctx, env)`**，`env = { session: { key } }`（宿主按当前会话标签逐个调）
- 返回 `{ icon, tone, tip }`：`icon` 同 §3.3 三来源；`tone` 走 token（绿=`accent`/灰=`text.faint`）；
  `tip` 为文案对象
- 重渲节拍 = 宿主会话事件 + 回调链返回后（宿主不 watch 插件文件）

## 4B. 弹窗（popup，v3）

通用**非模态**弹窗：宿主管窗体（尺寸档位映射、定位、随手关闭），插件只给内容树与开关意图。

- 清单：`[[contributes.popups]]`，字段 `id` / `title` / `size`（`SM/MD/LG` 档位，
  MD≈500x500，实现值归宿主，插件不写像素）/ `entry`（逻辑入口）
- 插件导出 **`render_popup(ctx)`** 返回内联树（同面板渲染规则，v3 宿主按它出弹窗内容）
- `ctx.act.openPopup(id)` / `ctx.act.closePopup(id)` 在任意回调内开/关
- 重渲与回调链同面板；「自动弹出」只能在宿主对可见页的回调里发生（页面未激活不产生回调 → 不弹）

## 5. 大批量列表（v2 不做）

v2 里插件直接吐**内联树**：20 个快捷方式就写 20 个 `button`，宿主零解析。
`list`（虚拟滚动 + 行模板）推迟到真有上千行时再引入——那时连同契约版本一起升。

## 6. 数据与状态（v2：插件自管）

**没有数据源、没有 `$字段` 占位、没有 `$auto`。** 数据是插件自己的事：

- **存放**：插件私有目录 `ctx.dir`，读写走 `ctx.fs.read/write/list`（02 §3），PF 不解析内容；
- **计算**：过滤、排序、取短名、判定可执行，全在 `render(ctx)` 里算完，返回**值已内联**的树；
- **宿主不知道** `pins`、不知道 `isExec`、不知道任何字段名。

已删除的历史包袱（出现即 `check` 报错，U6）：`source` / `filter{field,equals}` /
`groupBy` / `$name` / `$path` / `$fileIcon` / `$auto` / `render` 返回的 `rows`。

## 7. 样式 token（唯一合法取值）

所有样式属性只能填下列 token 名，**不得出现数值**。

| 类别 | 合法取值 | 来源 |
|---|---|---|
| 间距 / 内边距 / gap | `SP1`…`SP10` | `ui::tokens::space`（主库规范 §1） |
| 图标尺寸 | `INDICATOR` `XS` `SM` `MD` `LG` | `ui::tokens::icon`（§3） |
| 圆角 | `XS` `CTRL` `CARD` `MODAL` `SHEET` | `ui::tokens::radius`（§4） |
| 按钮尺寸 | `SM` `MD` `LG` | `ui::tokens::btn`（§5.1） |
| 字号 | `XS` `SM` `MD` `LG` | 主库规范 §2 / §10.5 |
| 颜色 | theme 字段名（如 `text` `text.muted` `accent` `danger` `bg.hover`） | `appearance::theme` |
| 行高 | `ROW` `TWO_LINE` | 主库规范 §5.8 实测 |

渲染硬约束（宿主强制，插件无法覆盖）：字号经 `appearance::ui_size` 走用户缩放；
密度、DPI、暗色/亮色由 theme 决定；hover / selected / disabled 四态配色走主库规范 §6。

## 8. 动作（宿主执行）

| 动作 | arg | 行为 |
|---|---|---|
| `run` | 路径 | 021 执行链，新终端 tab |
| `edit` | 路径 | 编辑器打开（后缀路由到查看器/源码） |
| `reveal_in_explorer` | 路径 | 资源管理器定位 |
| `toast` | 文本 | 轻提示 |
| `open_url` | URL | 系统浏览器 |
| `ask_pi` | 文本 | **预填**输入框并聚焦；发不发由用户按发送键（插件不代发） |
| `new_session` | — | 新建空白会话 |
| `open_folder` | 路径 | 资源管理器打开该目录（不是切换工作区） |

- 白名单外动作 → `check` 报错；运行期遇到 → 按钮禁用 + 「宿主不支持」tooltip。
- **`$auto` 已删除**：可执行→`run`、文档→`edit` 是**插件策略**，插件用
  `ctx.isExecutive(path)` 自己判，宿主只负责执行。
- 改自己的数据（移除快捷、改名…）不是动作，走 `ctx.onCommand`（§4.2）。
- 插件与 `ctx` 对应关系：`open_url`→`ctx.openUrl`、`open_folder`→`ctx.openFolder`、
  `new_session`→`ctx.newSession()`、`ask_pi`→`ctx.askPi(text)`。
- `ask_pi` 刻意**不做自动发送**：插件不得替用户提交请求（重放/误触发风险）。

## 9. 校验规则

`scripts/check.mjs` 与宿主解析器**同读** `schema/plugin-contract.json`，规则如下：

| # | 规则 |
|---|---|
| U1 | 组件 `type` 必须在 §1 封闭清单内（= 契约 `primitives`） |
| U2 | 样式属性值必须在 §7 token 表内；**出现数字即报错** |
| U3 | 颜色属性必须在 theme 字段名内；出现 `#`/`rgb` 即报错 |
| U4 | `icon` 必须是 §3.3 三来源之一；`assets:<名>` 必须在包内存在且为单色 SVG |
| U5 | `action` 必须在 §8 白名单内；带 arg 的动作必须给 `arg` |
| U6 | **禁用**废弃键：`source` / `filter` / `groupBy` / `$auto` / `$<字段>` / `rows` |
| U7 | 文案对象 `zh` 必填（纯字符串 `label` 除外） |
| U8 | `menu[].id` kebab-case 且插件内唯一；带 `action` 的还必须满足 U5 |
| U9 | `pf-plugin.toml` 只许 `schema/id/title/version/contributes`；`layout`/`store`/`wasm`/`api` 出现即错 |
| U10 | 包结构 = `pf-plugin.toml` + `main.js` +（可选）`assets/`；出现 `package.json`/`src/`/`plugin.wasm`/`store.json` 即错 |
| U11 | `grid.minItem` ∈ `SM/MD/LG`；`grid` 不得嵌套 `grid`；`grid` 的子项不得再是容器 |
| U12 | `panel-frame.children` 必须是 1..4 个 `section`；`section` 只能出现在 `panel-frame` 内；`panel-frame` 不得嵌套 |
| U13 | `pf-plugin.toml` 的 `schema` 必须等于契约的 `manifest_schema`（当前 2）；更高版本 = 拒装 |
| U14 | `main.js` 不得引用 `ctx.hostProof`——内层 wasm 插件专用（90-4 §7），判定材料不进公开包 |

## 10. 完整示例：收藏面板（照此可画出，无需其它信息）

`main.js` 的 `render(ctx)` 返回值——这就是收藏面板的全部 UI，插件侧 0 个色值、宿主侧 0 行插件语义。

```js
export function render(ctx) {
  // 1) 数据自己读、自己算（ctx.dir 下的 pins.json，只存路径数组）
  const pins = JSON.parse(ctx.fs.read("pins.json") || "[]");
  const exec = pins.filter((p) => ctx.isExecutive(p));
  const docs = pins.filter((p) => !ctx.isExecutive(p));

  // 2) 值内联、动作显式：run / edit 由插件决定
  const cell = (p, action) => ({
    type: "button",
    icon: ctx.fileIcon(p),                 // 不透明引用，原样透传
    label: basename(p),                    // 数据文案：纯字符串
    tip: p,                                // hover 全路径
    action, arg: p,
    menu: [
      { id: "reveal", title: { zh: "定位文件" }, action: "reveal_in_explorer", arg: p },
      { id: "unpin",  title: { zh: "移除收藏" } },   // 无 action → 回调插件
    ],
  });

  // 外壳归宿主：两个分区各自滚动、中间分隔线可拖拽（project panel 同款）
  return { type: "panel-frame", children: [
    { type: "section", title: { zh: "可执行文件", en: "Executables" },
      children: [{ type: "grid", minItem: "SM", children: exec.map((p) => cell(p, "run")) }] },
    { type: "section", title: { zh: "文档与代码", en: "Docs & Code" },
      children: [{ type: "grid", minItem: "SM", children: docs.map((p) => cell(p, "edit")) }] },
  ] };
}
```

空态同理，由插件给：两个 `group` 都不给 `children` 时自己插一条 `text`：

```js
{ type: "text", value: { zh: "在文件树右键 → 插件 → 加入收藏", en: "Right-click a file → Add Pin" },
  tone: "text.faint" }
```

包结构：

```
example-plugin/
  pf-plugin.toml     清单（id / version / contributes）
  main.js            activate(ctx) / render(ctx)
  assets/icon.svg    状态栏 tab 图标
  data/              运行时由 PF 建，插件私有（不进包）
```

## 11. v2 覆盖度与缺口

| 插件 | 覆盖 | 缺口 |
|---|---|---|
| **收藏面板** | ✅ 完全够用：`panel-frame` + `section` + `grid` + `button` + `menu` + 三来源图标 | 无 |

v2 明确不做：虚拟滚动、键盘导航、拖拽、行内编辑、`input`、`tree`、`diff`、`webview`。
