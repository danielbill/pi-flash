# 90-3 插件系统 UI 组件规范

> 当前契约 = 插件仓（pi-flash-plugins）**`schema/plugin-contract.json`**，版本
> **pf-plugin-contract/5**（`manifest_schema = 5`；宿主 `SUPPORTED_MANIFEST_SCHEMA = 5`，
> 装包兼容 3/4）。
> **插件不绘制任何像素**：插件返回**已算好的组件树**
> （值内联、动作显式），宿主是树解释器。本文件是 UI 契约的散文版，
> 机器真源在插件仓（check.mjs 读它校验）；宿主解析器按本文实现，
> 两者不一致以代码为准并改本文。
> **布局裁决权归宿主**：插件只声明结构与档位，尺寸/列数/换行/DPI 由宿主定；
> 宿主**不得**按插件类型或组件组合去猜布局（“连续 `button` 就摊成格子”是禁止的）。
>
> 上位规范：`docs/UI设计/UI组件规范.md`（下文简称**主库规范**）。
> 插件侧样式一律先写 token 名（§7），数字 px 只在弹窗精确对齐类场景使用。
> 清单与贡献点规范见 90-2（`90-2-插件清单与贡献规范.md`）；
> 存储与 ctx 能力面见 90-4（`90-4-插件存储与运行.md`，下称 90-4）。

## 0. 定位与边界

| 归属 | 内容 |
|---|---|
| **插件声明** | 组件树结构、文案、内联的值、动作、图标引用 |
| **宿主渲染** | 布局、滚动、焦点、hover、右键菜单、主题色、密度、DPI |
| **宿主执行** | 动作（打开文件、跑脚本、开链接…），插件拿不到执行权 |

三条铁律：

1. **档位优先于数值**：样式一律先写 token 名（§7）；仅 `gap`/`pad`/`padX`/`padY`/
   `w`/`radius` 与 canvas 坐标允许数字 px（弹窗精确对齐类场景），颜色只许
   token 名，唯一例外 `canvas.fill` 字面色（图形语义 ≠ 主题语义）。
2. **零绘制**：插件不产 display list、不调 gpui、不含 UI 代码。
3. **零字段解析**：插件返回的树里**值已内联**——宿主不认字段名、不做过滤、
   不折算动作。数据从哪来、怎么算，全在插件里（存储见 90-4 §3）。

## 1. 组件词表（封闭清单）

**封闭**：不在本表的组件，`check` 直接报错；宿主渲染到未知组件置为占位块并记录日志。

| 组件 | 用途 | 对应宿主实现 |
|---|---|---|
| `panel-frame` | **面板外壳**：分区 + 各自滚动 + 可拖拽分隔线（宿主画） | 与 project panel 同款骨架 |
| `section` | 一个分区（只能出现在 `panel-frame` 内） | 分区标题 + 内容 |
| `column` | 纵向容器（内容区内部用） | `div().flex_col()` + kit 间距 |
| `row` | 横向容器（放不下自动换行） | `div().flex_row()` + `flex_wrap` |
| `group` | 分组标题 + 内容 | 宿主固定分组标题样式（§2.3） |
| `grid` | 等宽格子流（通用） | 宿主按面板宽度算列数后铺 equal-width 网格 |
| `divider` | 分隔线 | 主库规范 §5.13 统一分隔线的发丝线形态 |
| `text` | 文本 | 面板轨文本块（主库规范 §10.3） |
| `icon` | 图标 | `ui::icon` / `icon_path`（§3.3 三来源） |
| `button` | 按钮；格子/行也用它 | 三形态按钮（§4.1） |
| `canvas` | 通用画布（paint list 绝对定位绘制） | 定宽高裁剪容器 + 逐条绘制（§3.6） |
| `switch` | 开/关开关 | 宿主统一开关样式；点击翻转 → `onCommand(command,{value:新布尔})` |

**不在词表**：`list` / `input` / `checkbox` / `slider` / `tree` / `badge` /
`tooltip` / `image`（图形走 `canvas` 直画）/ `spacer` / `webview` / 任意自绘容器。
加组件 = 改宿主解释器 + 升契约 `manifest_schema`（宿主拒装旧清单）+ 同步插件仓契约 JSON。
`list`（虚拟滚动 + 行模板）仍不在词表，行数上千时随契约升版一并办理。

## 2. 结构组件

### 2.1 `column`

```jsonc
{ "type": "column", "gap": "SP3", "pad": "SP4", "children": [ /* … */ ] }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `gap` | token `space.*` 或数字 px | 子项间距（缺省 SP2 = 4px） |
| `pad` | token 或数字 px | 内边距，横纵同值（缺省 SP5 = 10px） |
| `padX` / `padY` | 数字 px | 覆盖横向/纵向内距（缺省回落 `pad`） |
| `w` | 数字 px | 固定宽度（夹住内容列） |
| `bg` | 颜色名（§7） | 可选底色 |
| `radius` | 数字 px | 可选圆角（配 `bg` 成卡片，溢出裁剪） |
| `border` | 颜色名（§7） | 可选 1px 描边 |
| `align` | `start` / `center` / `end` / `stretch` | 交叉轴对齐；宿主实现取 `center`，其余按缺省排版 |
| `justify` | `start` / `center` / `end` / `between` | 主轴（纵向）对齐；宿主实现取 `center`（空态提示整块居中），其余顶对齐 |
| `children` | 组件数组 | — |

> `column` **没有** `scroll`：滚动只发生在 `panel-frame` 的 `section` 里（§2.6）。
> 需要一整块可滚动 → 用 `panel-frame` + 一个 `section`。

### 2.2 `row`

```jsonc
{ "type": "row", "gap": "SP3", "children": [ /* … */ ] }
```

横排版的 `column` 同名属性：`gap`（缺省 SP3 = 6px）、`pad`（缺省 0）、
`align`（`start` / `center` / `end`，缺省 `stretch` = 不另设）、
`justify`（`between` / `end` 独立生效，**其余取值含缺省 = 居中**）。
子项放不下自动换行。契约 tokens 另登记 `row.w`，宿主渲染暂未消费（写了不生效）。

### 2.3 `group`

分组标题 + 内容，标题样式宿主固定：居中一行（行高 24px）、ui(12) semibold、
色 `text.dim`；插件不得改字号/颜色。`title` 为空串时不画标题行。

```jsonc
{ "type": "group", "title": { "zh": "可执行文件", "en": "Executables" },
  "children": [ /* … */ ] }
```

### 2.4 `grid`

**等宽格子流**：每个 child 占一格。这是通用原语（快捷方式、图片墙、模板选择同类），
宿主里没有任何插件语义。

```jsonc
{ "type": "grid", "minItem": "SM", "children": [ /* 每项一格 */ ] }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `minItem` | `SM` / `MD` / `LG` | **建议**最小格宽档位，宿主映射到实现值（88/120/160px），缺省 `SM`，插件不写数值 |
| `children` | 组件数组 | 每项占一格；**不得嵌套 `grid`**，子项不得再是容器 |

**谁决定什么**：

| 归属 | 内容 |
|---|---|
| 插件 | 这是格子流 + 建议档位 + 每格内容（图标/文案/动作） |
| 宿主 | 列数 `clamp(floor(可用宽 / 档位宽), 1, 6)`（可用宽 = 面板宽 − 2×外壳留白）、格宽撑满列、格子间距 4px、换行、标签省略、DPI |

格子等宽、可随面板变宽而变宽（标签占满列宽 → 名字显示更多）；宽度上限由列数公式兜住，
不会出现“一行一个巨格”。

> **禁止**：宿主不得从“`column` 里连续放了几个 `button`”之类形态猜出格子布局。
> 想要格子就显式写 `grid`——这一条是契约级的，见契约 JSON 的 `layout_ownership`。

### 2.5 `divider`

```jsonc
{ "type": "divider" }
```

宿主固定形态：左右 10px、上下 6px 纵向留白，1px 发丝线（`text` 低透明度上色，
线形归属主库规范 §5.13 统一分隔线）。词表无 `spacer`（横向留白用 `row.justify`，
纵向用容器 `gap`/`pad`）。

### 2.6 `panel-frame`（面板外壳，宿主画）

**视觉一致性由宿主保证**：分区标题样式、每个分区各自滚动、中间分隔线可上下拖拽、
内边距、滚动条——全部与 project panel 同款。插件不再用 `column`/`divider` 手拼外壳。

```jsonc
{ "type": "panel-frame", "children": [
    { "type": "section", "title": { "zh": "程序" }, "icon": "play", "children": [ /* 内容 */ ] },
    { "type": "section", "title": { "zh": "文档" }, "icon": "assets:doc.svg", "children": [ /* 内容 */ ] } ] }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `children` | 1..4 个 `section` | 1 个 = 不分区（整块滚动）；多个 = 上下分区 |
| `section.title` | 文案对象（可省） | 文案插件给，样式宿主定 |
| `section.icon` | 图标引用（可省） | 内置名（如 `play`）或 `assets:doc.svg`，与 `button.icon` 同规则 |

**分工：插件给意图，宿主算像素**（这是全契约的通用口径，不针对某个面板）：

| 谁定 | 定什么 |
|---|---|
| 插件 | `titleAlign`（`start` / `center` / `end`）、`titlePad`（**SP token** 或数字 px，如 `SP8`） |
| 宿主 | token→px、DPI 缩放、标题字号/字重/图标档、以及缺省值兜底 |

宿主固定部分：外壳留白 `PANEL_PAD`（=12px）、
标题上方 8px、图标 **MD=16px** + 6px 间距 + **body=ui(12) semibold** 文字、
标题色 **`text.faint`**。

> **分区标题是次要信息**：颜色必须比内容淡，不许抢视觉；缩进比内容再进一档
> （示例用 `titlePad: "SP8"` = 20px）。
`titlePad` 比外壳留白大就补差额，小则不外扩（不出现负 padding）；缺省 0 = 贴外壳留白。

**插件仍然优先写 token**：`titlePad` 写 `SP8`，不要写 `20`。

| 归属 | 内容 |
|---|---|
| 插件 | 分几个区、每区标题、每区内容（内部再用 `column`/`grid`/`button`…） |
| 宿主 | 外壳布局、分区标题样式、各自滚动与滚动条、分隔线拖拽、各区间比例、内边距 |

分区比例是**宿主 UI 状态**（内存态，重启回等分，分区数变了重置等分），**不写进插件数据**；
分隔线命中区走主库规范 §5.13 统一实现（常驻 1px，hover/拖拽 accent 高亮），
拖到极限每区保底 12% 占比、不消失。

**禁止**：插件用 `column` + `divider` 手工拼出“看起来像分区”的东西；要分区就用 `panel-frame`。

### 2.7 `section`（分区）

只允许作为 `panel-frame` 的直接子项；`children` 为该区内容。出现在别处 = `check` 报错。
`title` / `icon` 都可省（两个都没给则只画内容，不画标题行）。

## 3. 内容原子

### 3.1 `text`

```jsonc
{ "type": "text", "value": { "zh": "…", "en": "…" }, "tone": "text.muted", "size": "SM" }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `value` | 文案对象（`zh` 必填，`en` 可省）或纯字符串 | 纯字符串 = 数据文案 |
| `tone` | `text` / `text.muted` / `text.dim` / `text.soft` / `text.faint` / `accent` / `danger` | 主题词表，禁色值；宿主映射中 `text.soft` 与未知值同落 `text.dim` |
| `size` | `XS` / `SM` / `MD` / `LG` | 10/11/12/14，经 `ui_size` 随用户字号缩放；缺省 `SM` |
| `weight` | `regular` / `medium` / `semibold` | 缺省 `regular` |
| `ellipsis` | `bool` | 超宽省略（缺省 `true`） |

### 3.2 `icon`

```jsonc
{ "type": "icon", "name": "file-text", "size": "SM", "tone": "text.muted" }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `name` | 见 §3.3 三种来源 | 缺省 `file` |
| `size` | `INDICATOR` / `XS` / `SM` / `MD` / `LG` | 五档固定 px（10/12/14/16/18），不随用户字号缩放；缺省 `SM` |
| `tone` | 同 `text.tone` | 宿主据此给 SVG 上色；缺省 `text` |

### 3.3 图标来源（三种，互斥）

| 写法 | 来源 | 用法 |
|---|---|---|
| `"name": "<资源名>"` | 宿主内置 `crates/app/assets/icons/<名>.svg`（现 112 个，§3.4） | 通用 UI 图标 |
| `"name": "<ctx.fileIcon() 的返回值>"` | 宿主预解析好的文件图标路径（`icons/file_icons/…`，含 `/` 原样透传） | 列表行 / 文件相关处 |
| `"name": "assets:<文件名>"` | **插件包自带** `assets/` 下的 SVG | 插件专属图标 |

```jsonc
{ "type": "icon", "name": "assets:gitee.svg" }          // 包内 assets/gitee.svg，文件名含扩展名
{ "type": "icon", "name": "icons/file_icons/ps1.svg" }  // ctx.fileIcon("x.ps1") 的返回值原样放回
```

注意 `"name": "file"` 只是内置通用文件图标，**不是**按后缀判定；按后缀判定必须走
`ctx.fileIcon(path)`（见下方解析规则表）。

**插件自带图标规范（硬性）**：

1. **单色 SVG**：路径只用 `fill="currentColor"` 或不写 fill；**禁** `#hex` / `rgb()` /
   渐变 / 多色 —— 宿主统一 `text_color` 上色，多色图标会在暗色主题下失效；
2. `viewBox="0 0 24 24"`，24 栅格对齐，无内边距留白；
3. 单文件 < 8KB，禁 `<image>` / 位图 / 字体 / 外部引用；
4. 文件名小写 kebab-case，`assets/` 下平铺（不建子目录）；
5. 引用写 `assets:<文件名>`，**文件名含 `.svg` 扩展名**（宿主按路径原样解析，不补扩展名）。

**宿主名不设白名单**：宿主不导出图标清单、`check` 也不校验内置名——未知名渲染为
空白（不报错、不兜底；空名兜底 `file`）。§3.4 即当前宿主资源全集，插件从中取名。

**`ctx.fileIcon(path)` 的解析规则**（`services::file_icons`，Zed file_icons 同表）：

| 文件形态 | 图标来源 | 说明 |
|---|---|---|
| 任意路径 | 后缀表多级匹配 | 完整文件名 → 逐段后缀 → 多重扩展名 → 扩展名/隐藏文件名（`.ps1`→终端、`.md`→文档…） |
| 判定不到 | 通用文件图标 `file` | 兜底，不报错 |

已知限制：`.exe` / `.lnk` 不做系统图标提取，同样走后缀表兜底。

解析结果对插件是**不透明引用**：`onMenu` 递来的 `fileIcon`、`ctx.fileIcon()` 的返回值，
插件**只透传**（直接放进 `button.icon`），不解释、不拆解、不自己拼 `icons/…` 路径
（90-4 §3 同款语义）；渲染时由宿主按引用还原图标。

### 3.5 图标与文字的排布（宿主固定，插件不可指定）

| 场景 | 规则 |
|---|---|
| 格子按钮（有图标有标签） | 图标上（30/36/44px 随 `size`）、标签下（ui(11) muted，超宽省略） |
| 纯图标按钮（`variant: "icon"`） | 方钮，label 退成 tooltip |
| 文字按钮（无图标） | 整行矮钮、文本省略 |
| `switch` 行 | label（ui(11.5) muted）+ 开关轨道，间距 8px |
| `group` 标题 | 居中一行，ui(12) semibold、`text.dim`（§2.3） |
| 分区标题 | 图标 MD=16px + 6px 间距 + ui(12) semibold、`text.faint`（§2.6） |
| 右键菜单行 | 图标 14px + 文本，行样式与文件树右键同源（§4.2） |

对齐、间距、图标与文本基线全部归宿主，插件不得用 `column`/`row` 手工摆位。
字号的各档经 `appearance::ui_size` 随用户字号缩放；图标档位是固定 px，不缩放。

### 3.6 `canvas`（通用画布）

```jsonc
{ "type": "canvas", "width": 392, "height": 392,
  "paint": [
    { "op": "rect", "x": 0, "y": 0, "w": 8, "h": 8, "fill": "#111827" },
    { "op": "text", "x": 12, "y": 24, "size": 11, "tone": "text.dim", "value": "hi" }
  ] }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `width` / `height` | 数字 px | 画布定宽高；paint 坐标裁剪在节点框内（不许逃逸） |
| `paint` | paint 数组 | 逐条绝对定位绘制；单画布上限 4096 条（超出截断） |
| `command` | kebab-case（可选） | 给了 = 整块画布即按钮，左键回环 `onCommand(command, env)`（见 §4.1 `command`） |

paint 只有两种 op：`rect{x,y,w,h,fill}`（实心方块；`fill` 允许 `#rgb`/`#rrggbb`
字面色，非法值跳过上色）与 `text{x,y,size,tone,value}`（`size` 数字 px，`tone` 走
主题词表）。未知 op 解析期静默丢弃（不占位不报错）。宿主不解释图形含义
（二维码 = 调用方 run-length 合并的 rect 群）。

## 4. 交互组件

### 4.1 `button`

```jsonc
{ "type": "button", "label": { "zh": "新建会话", "en": "New Session" },
  "icon": "plus", "variant": "text", "action": "new_session" }
```

| 属性 | 取值 | 说明 |
|---|---|---|
| `label` | 文案对象 **或** 纯字符串 | 文案对象 `zh` 必填；数据文案（如文件名）直接给字符串 |
| `icon` | 图标引用（可选） | §3.3；`ctx.fileIcon()` 的返回值原样放这里 |
| `variant` | `text` / `icon` | `icon` = 纯图标方钮；缺省 `text` |
| `size` | `SM` / `MD` / `LG` | 缺省 `MD` |
| `tip` | 字符串 | hover 提示（如全路径）；纯图标钮缺省用 `label` 兜底 |
| `action` | §8 动作名 | **宿主执行**，插件无回调 |
| `arg` | 动作参数 | 见 §8；无 `action` 时作为菜单回调的 `{ path }` 递回 |
| `command` | kebab-case（可选） | 左键回环插件命令 `ctx.onCommand(command, env)`；**优先于 `action`**；`arg` 为空时宿主自动补 `{session:{key}}`（与 `switch.command` 同口径） |
| `menu` | 菜单项数组 | 右键菜单，见 §4.2 |
| `disabled` | `bool` | 插件自己算；宿主只画禁用态 |

**三形态**（宿主按字段自动选择，插件不额外声明）：

| 形态 | 条件 | 宿主样式 |
|---|---|---|
| 格子 | 有 `icon` 有 `label` | 图标上、标签下，高 64/76/92（随 `size`） |
| 纯图标钮 | `variant: "icon"` | 方钮边长 28/34/40，圆角 CTRL |
| 文字钮 | 无 `icon` | 整行矮钮、文本省略 |

死按钮（不接线、`text.dim`）的条件：`disabled`，或无 `command` 且无有效 `action`。
按钮不定义颜色：常态 / 悬停（`bg.hover`）/ 禁用全由 theme + 主库规范 §6 决定。

### 4.2 右键菜单项（`menu`）

```jsonc
"menu": [
  { "id": "unpin", "title": { "zh": "移除收藏" }, "icon": "trash", "danger": true }
]
```

| 字段 | 取值 | 说明 |
|---|---|---|
| `id` | kebab-case，插件内唯一 | 回调时原样递回 |
| `title` | 文案对象 | 不带 `action` 时必填 |
| `icon` | 图标引用（可省） | 与 `button.icon` 同规则（内置名或 `assets:`） |
| `danger` | `bool` | 红字 + 红 hover（删除类） |
| `action` / `arg` | §8 动作 | 带 = 宿主执行；不带 = 回调 `ctx.onCommand(id, { path })` |

**样式与文件树右键菜单同源**（同一卡座 `menu_card`、同一行 `menu_item_asset`、
同一浮层 `psp-overlays`）：行高、图标 14px、hover、贴边翻转、ESC/点外关闭全归宿主，
插件只给图标名与危险色标记。**插件不得自绘菜单**。
`action` 不在白名单的菜单项仍可点，点击 toast「宿主不支持的动作：N」。

### 4.3 `switch`

```jsonc
{ "type": "switch", "value": true, "label": { "zh": "开启/关闭示例服务" },
  "tip": "关闭即断开示例服务", "command": "toggle-enabled" }
```

| 字段 | 取值 | 说明 |
|---|---|---|
| `value` | **bool** | 当前布尔态（必填） |
| `command` | kebab-case | 必填；点击翻转后宿主回调 `ctx.onCommand(command, { value: 新布尔值 })` |
| `label` | 文案对象 | 可省（纯开关） |
| `tip` | 字符串 | 可省 |
| `disabled` | bool | 可省 |

`value` 非布尔、`command` 缺失或非 kebab-case 的节点宿主置占位并记日志。
样式（轨道 28×16 / knob 10 / 动画）全归宿主统一，插件只给态与回环。

## 4A. fn_bar 注册槽

会话标签**功能栏右侧的注册槽**：每个会话标签一个插件 icon 按钮，宿主统一 fn 样式
（大小/长宽/padding），按注册顺序从右到左排。

- 清单：`[[contributes.fn_bar]]`，唯一字段 `command`（点击回环 `ctx.onCommand`）
- 插件导出 **`fn_bar(ctx, env)`**，`env = { session: { key } }`（宿主按当前会话标签逐个调）
- 返回 `{ icon, tone, tip }`：`icon` 同 §3.3 三来源；`tip` 为文案对象或纯字符串；
  `tone` 走 token，宿主映射：`accent` → 主题绿（激活态语义）、`text.faint` → 灰
  （未绑默认）、其余 → `text.muted`
- 取数带 1s TTL 缓存（功能栏每帧渲染，不逐帧调插件）；命令回环后缓存作废重取
- 点击 = 若清单带包内 pi 扩展先挂载到当前会话（90-4 §8/§9），再回环 `command`
  （env 带当前会话键）
- 重渲节拍 = 宿主会话事件 + 回调链返回后（宿主不 watch 插件文件）

## 4B. 弹窗（popup）

通用**非模态**弹窗：宿主管窗体（尺寸档位映射、定位、随手关闭），插件只给内容树与开关意图。

- 清单：`[[contributes.popups]]`，字段 `id` / `title`（可空 = 不画标题栏）/
  `size`（`SM`/`MD`/`LG` 档位，缺省 `MD`）/ `entry`（逻辑入口，缺省 `main.js`）
- 尺寸档位宿主映射为实现值：SM 400×420、MD 420×630、LG 600×640（插件不写像素）
- 插件导出 **`render_popup(ctx)`** 返回内联树（同一解释器渲染；未导出退回 `render`）；
  返回 `null` = 此刻无内容 → 不开/自动关
- `ctx.act.openPopup(id)` / `ctx.act.closePopup(id)` 在任意回调内开/关；
  `id` 未在清单声明 → 宿主不开窗并状态栏提示
- 窗体为非模态居中卡：不压暗背景、不抢焦点，外点/× 关闭；**一次只开一个**
  （开新的关旧的），内容按 1s 节拍轮询重取
- 「自动弹出」只能在宿主对可见页的回调里发生（页面未激活不产生回调 → 不弹）

## 5. 大批量列表

当前词表没有 `list`：插件直接吐**内联树**，20 个快捷方式就写 20 个 `button`，宿主零解析。
虚拟滚动 + 行模板的 `list` 仍未引入；真有上千行的需求时随契约升版一并办理。

## 6. 数据与状态（插件自管）

**没有数据源、没有 `$字段` 占位、没有 `$auto`。** 数据是插件自己的事：

- **存放**：插件私有目录 `ctx.dir`，读写走 `ctx.fs.read/write/list`（90-4 §3），PF 不解析内容；
- **计算**：过滤、排序、取短名、判定可执行，全在 `render(ctx)` 里算完，返回**值已内联**的树；
- **宿主不知道** `pins`、不知道 `isExec`、不知道任何字段名。

禁用键（出现即 `check` 报错，U6）：`source` / `filter{field,equals}` /
`groupBy` / `$name` / `$path` / `$fileIcon` / `$auto` / `render` 返回的 `rows`。

## 7. 样式 token（唯一合法取值）

样式属性优先只填下列 token 名；数字 px 仅限 §0 铁律 1 列明的属性。

| 类别 | 合法取值 | 宿主落点 |
|---|---|---|
| 间距 / 内边距 / gap | `SP1`…`SP10`（= 2/4/6/8/10/12/16/20/24/32px） | `ui::tokens::space`（主库规范 §1） |
| 图标尺寸 | `INDICATOR` `XS` `SM` `MD` `LG`（= 10/12/14/16/18px） | `ui::tokens::icon`（§3） |
| 圆角 | `XS` `CTRL` `CARD` `MODAL` `SHEET` | `ui::tokens::radius`（§4）；`column.radius` 例外 = 数字 px |
| 按钮尺寸 | `SM` `MD` `LG` | 格子高 64/76/92、格内图标 30/36/44；纯图标钮边长 28/34/40（§4.1） |
| 字号 | `XS` `SM` `MD` `LG`（= 10/11/12/14，经 `ui_size` 缩放） | 主库规范 §2 / §10.5 |
| 颜色 | tone 词表（§3.1）；`column.bg`/`border` 另收 `bg` `bg_panel` `chrome` `border` `white`；`canvas.fill` 允许 `#hex` | `appearance::theme` 映射 |

渲染硬约束（宿主强制，插件无法覆盖）：字号经 `appearance::ui_size` 走用户缩放；
密度、DPI、暗色/亮色由 theme 决定；hover / selected / disabled 交互态配色走主库规范 §6。

## 8. 动作（宿主执行）

| 动作 | arg | 行为 |
|---|---|---|
| `run` | 路径 | 021 执行链，新终端 tab（`script_exec` 解析失败 → 状态栏报错） |
| `edit` | 路径 | 编辑器打开（后缀路由到查看器/源码） |
| `reveal_in_explorer` | 路径 | 资源管理器定位 |
| `toast` | 文本 | 轻提示（状态栏） |
| `open_url` | URL | 系统浏览器 |
| `ask_pi` | 文本 | **预填**输入框并聚焦；发不发由用户按发送键（插件不代发） |
| `new_session` | — | 新建空白会话 |
| `open_folder` | 路径 | 资源管理器打开该目录（不是切换工作区） |

- 白名单外动作 → `check` 报错；按钮上遇到 → 禁用；菜单项上遇到 → 点击 toast「宿主不支持的动作：N」。
- 可执行→`run`、文档→`edit` 是**插件策略**，插件用
  `ctx.isExecutive(path)` 自己判，宿主只负责执行。
- 改自己的数据（移除快捷、改名…）不是动作，走 `ctx.onCommand`（§4.2）。
- 插件与 `ctx` 对应关系：`open_url`→`ctx.openUrl`、`open_folder`→`ctx.openFolder`、
  `new_session`→`ctx.newSession()`、`ask_pi`→`ctx.askPi(text)`（动作命名空间
  `ctx.act.*` 同面，见 90-4 §3）。
- `ask_pi` **不做自动发送**：插件不得替用户提交请求。

## 9. 校验规则

校验入口 = **插件仓** `scripts/check.mjs`：读契约 JSON 校验清单字段、包结构与
`main.js` 静态面，并用假 `ctx` 跑一次 `render` 逐节点校验；宿主解析器
（`pf_plugin::panel`）按同一套规则独立解析——非法节点占位/丢弃 + 日志，不硬失败。
规则编号被两侧代码注释引用：

| # | 规则 |
|---|---|
| U1 | 组件 `type` 必须在 §1 封闭清单内（= 契约 `primitives`）；宿主渲染到未知组件置占位块并记日志 |
| U2 | 样式属性值必须在 §7 token 表内；`gap`/`pad` 允许数字 px，`size` 只许 token（数字即报错） |
| U3 | 颜色属性必须在 tone 词表内，出现 `#`/`rgb` 即报错；唯一例外 `canvas.fill` 字面色 |
| U4 | `icon` 必须是 §3.3 三来源之一；`assets:<名>` 必须在包内存在且为单色 SVG（内置名不校验清单，未知名渲染为空白） |
| U5 | `action` 必须在 §8 白名单内；带 arg 的动作必须给 `arg` |
| U6 | **禁用**废弃键：`source` / `filter` / `groupBy` / `$auto` / `$<字段>` / `rows`（`check` 静态扫 `main.js`） |
| U7 | 文案对象 `zh` 必填（纯字符串 `label` 除外） |
| U8 | `menu[].id` kebab-case 且插件内唯一；带 `action` 的还必须满足 U5；不带 `action` 必须给 `title` |
| U9 | `pf-plugin.toml` 顶层（标准包）只许 `schema/id/title/version/contributes`；`layout`/`store`/`api` 出现即错；宿主解析器另认内层/字节码包的 `wasm`/`bytecode` |
| U10 | 包结构 = `pf-plugin.toml` + `main.js` +（可选）`assets/`；出现 `package.json`/`src/`/`plugin.wasm`/`store.json` 即错（内层 wasm 包形态除外，90-4 §7） |
| U11 | `grid.minItem` ∈ `SM/MD/LG`；`grid` 不得嵌套 `grid`；`grid` 的子项不得再是容器 |
| U12 | `panel-frame.children` 必须是 1..4 个 `section`；`section` 只能出现在 `panel-frame` 内；`panel-frame` 不得嵌套 |
| U13 | `pf-plugin.toml` 的 `schema` 必须等于契约的 `manifest_schema`（当前 5）；`check` 要求恰为 5，宿主装包兼容 3/4，更高/其它版本 = 拒装 |
| U14 | `main.js` 不得引用 `ctx.hostProof`——内层 wasm 插件专用（90-4 §7），判定材料不进公开包 |

## 10. 完整示例：收藏面板（照此可画出，无需其它信息）

`main.js` 的 `render(ctx)` 返回值——这就是收藏面板的全部 UI，插件侧 0 个色值、宿主侧 0 行插件语义。

```js
export function render(ctx) {
  // 1) 数据自己读、自己算（ctx.dir 下的 pins.json，只存路径数组）
  const pins = JSON.parse(ctx.fs.read("pins.json") || "[]");
  const exec = pins.filter((p) => ctx.isExecutive(p));
  const docs = pins.filter((p) => !ctx.isExecutive(p));

  // 2) 值内联、动作显式：run / edit 由插件决定
  const cell = (p, action) => ({
    type: "button",
    icon: ctx.fileIcon(p),                 // 不透明引用，原样透传
    label: basename(p),                    // 数据文案：纯字符串
    tip: p,                                // hover 全路径
    action, arg: p,
    menu: [
      { id: "reveal", title: { zh: "定位文件" }, action: "reveal_in_explorer", arg: p },
      { id: "unpin",  title: { zh: "移除收藏" } },   // 无 action → 回调插件
    ],
  });

  // 外壳归宿主：两个分区各自滚动、中间分隔线可拖拽（project panel 同款）
  return { type: "panel-frame", children: [
    { type: "section", title: { zh: "可执行文件", en: "Executables" },
      children: [{ type: "grid", minItem: "SM", children: exec.map((p) => cell(p, "run")) }] },
    { type: "section", title: { zh: "文档与代码", en: "Docs & Code" },
      children: [{ type: "grid", minItem: "SM", children: docs.map((p) => cell(p, "edit")) }] },
  ] };
}
```

空态同理，由插件给：两个 `group` 都不给 `children` 时自己插一条 `text`：

```js
{ type: "text", value: { zh: "在文件树右键 → 插件 → 加入收藏", en: "Right-click a file → Add Pin" },
  tone: "text.faint" }
```

包结构：

```
example-plugin/
  pf-plugin.toml     清单（id / version / contributes）
  main.js            activate(ctx) / render(ctx)
  assets/icon.svg    状态栏 tab 图标
  data/              运行时由 PF 建，插件私有（不进包）
```

## 11. 覆盖度与缺口

当下词表（12 原语）已覆盖收藏面板类（`panel-frame` + `section` + `grid` + `button` +
`menu` + 三来源图标）与远程操控类的静态面（`text`/`button`/`canvas`/`switch` 组合）；
git 面板类需要的 `tree`/`diff`/虚拟滚动 `list`/键盘导航均不在词表——未开放，
引入随契约升版办理。
