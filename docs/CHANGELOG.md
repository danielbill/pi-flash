## [0.2.1] - 2026-10-20

本版聚焦各种崩溃bug性能优化：
中文 markdown 编辑「进程瞬间消失」崩溃修死；
terminal录入exit导致崩溃；
会话发送排队体系上线：运行中发言「排队 / 插话」两档可配；
内存占用优化；
超大文件目录打开卡顿修复。


### 安装与更新

```bash
npm install -g pi-flash@latest   # 首次安装与更新同命令
pi-flash
```

需要 Node.js ≥ 22.19。
也可直接下载 zip 绿色包，解压后双击 `pi-flash.exe` 即用，无需 Node。
仅提供 Windows x64 版本。


### 新增

- 会话发送排队体系：Agent 运行中再发消息不再「总是插队、冲进当前任务」——默认排队档进入本地队列，本轮结束自动发出；排队卡挂在输入面板上方，支持拖拽重排、铅笔撤回编辑、「立即」打断、垃圾桶删除；缓冲栏已有排队消息时禁止继续入队；停止按钮同步撤回排队消息；ESC 叫停排队；微信远程发送走同一漏斗。设置「其他」页新增「运行中发送方式」两档：排队（默认）/ 插话。(aa5c4fc, 551fa2b, edc23ce, 8f6a1cf, 14e6059, 3367977)
- 运行中「插话 / 立即」改打断语义：立即中止当前回复并重新下达指令，被打断的回复保留半截内容，新指令带着上文继续。(edc23ce)
- 会话 / 文件树操作栏不常用图标自动隐藏，悬停操作栏才显影；设置「界面」页新增「部分操作隐藏」开关（默认开，关掉恒显、即切即生效）。(98cbd72, 4bf8673)


### 修复

- 中文 markdown 编辑进程瞬间消失：编辑中文文章时窗口无报错直接消失（真机连崩三例，自动保存救回内容）——vendor 编辑器层 tree-sitter 高亮回调裸切片，脏偏移落在汉字（3 字节）中间时 panic 无法跨界 unwind 直接 abort；根因是 IME 组合更新（替换已标记文本）时选区基准错加旧替换区间末尾。回调加字符边界守卫 + 选区基准改正。(6e9af0e)
- 运行中打断一批：思考中插话把整屏消息拽到屏幕下半部分（打断只退役跟尾期锚点）；发言钉顶改按「是否真打断」决定；回显不补刀；stream_cut 残包并回旧回复。(92ff894, 0343a22)
- 思考强度换挡后胶囊仍显示旧档（真机怎么换都停在 high）。(3ae6f31)
- 终端两处：终端区变矮瞬间按旧行列数越界绘制崩溃；终端里裸敲 `exit` 回车不再连锁退出上级 shell，改为关闭当前终端标签页。(faf8987, c4d0aa1)
- 图片气泡不再显示 `[Image: original …]` 坐标标注。(5947554)
- 以子目录打开的仓库文件树展开卡死：git status / numstat 路径钉定仓库根并重定基。(0eefea6)
- 上下文用量弹窗加宽 40px（420 → 460），英文界面底部三钮不再溢出。(2a73342)
- 扩展详情状态行不再打印更新检测的原始错误串；「扩展」设置页导航项恢复（市场页上线时被误藏）。(bd21660, 6d26f83)
- 空闲会话发送不再误入排队缓冲；会话列表「回到最新」按钮在跟尾期不再失灵。(b2a56a3, 6a1dfb1)

### 改进

- 内存占用优化：解码位图缓存延迟驱逐（图片多的大会话内存只涨不降的根治）；空闲回收连 runtime 实体一起退役。(1f66410, b655602)
- 模型页与「添加 Provider」相关文案补齐繁中 / 英文翻译。(2042423, 271b653, 2cb104a)
- 快捷键页版式精简：去掉行内注释说明，只留标题与键帽。(af86124, 65fe2da)
- 会话内容宽度设置去掉「复位」按钮。(d64e64e)
## [0.2.0] - 2026-10-18

本版聚焦：性能大版本——巨大会话卡顿根治（688 条消息会话每帧成本 O(轮)→O(视口)、composer 打字不再每键整窗重绘、发送即冻死修复）；会话置顶、Pi 扩展更新检测、会话自动清理三大新特性；topbar 自由 tab 拖拽（Zed 同款）；RPC 中途停止不再静默。

pi-flash

### 新增
- 会话置顶（020）：会话行悬停出 pin 槽、右键卡 pin 钮，置顶组居列表首位（folder-bookmark 组头行）；原项目组按 pin 清单过滤，不重复显示。(c1f811f, d68112d, 42eaaf9, f652ad0)
- Pi 扩展更新检测与更新（082）：扩展管理页检测可用更新、一键全部更新；详情卡【更新】按钮仅在有可用更新时显示。(4fe2aeb, f3e860c, 02bb266)

- 注册项目零会话不再建空组——psp 不显示「无会话」占位项目。(2d1a5c0)
