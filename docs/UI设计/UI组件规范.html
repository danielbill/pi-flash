一切 padding / gap / margin 只取以下十档。行高（列表行、按钮、顶栏）是控件高度，走 §5 档位表，不受 4 倍数约束。

02

字号体系

双轨模型：ui_size(base) 面板轨随"界面字号"设置（10–17）缩放；sess_size(delta) 会话轨以正文为 0 按偏移取值。 下方样字以默认设置渲染：

caption · ui(10)徽标 · scope 标签 · stat 标签
secondary · ui(11)辅助说明 · 时间列 · git 面板正文 · footer
body · ui(12)面板正文 · 按钮 · 输入框 · 菜单行（基准档）
emphasized · ui(13)设置导航 · 富菜单主行 · 列表强调行
title · ui(14)弹窗标题 · pill 菜单 · 选中行主文字
会话轨正文 sess(0) · 操作栏 −1 · 气泡/工具卡 −2 · bash/meta −3
禁止：绕过双轨的裸 px(n) 与 tailwind text_sm / text_xs（存量 11 处待清）。 markdown / 终端（13px）/ TextInput 内部字号是渲染特例，值按规范记载的固定值执行。

07

对齐规则

表单行：标签右端对齐 → gap 8 → 控件；行距 12 · 区块间距 20
· 图标与文字一律垂直居中，禁止基线对齐
· 列表行内左对齐起于 pl10；时间/数字/快捷键列右对齐（pr10）
· 弹窗标题左对齐、关闭钮右上、按钮行右对齐
· 分栏容器：设置页左列表列宽统一 350（Providers/扩展/MCP/技能，基准 = 扩展页）；设置导航列 240；工具定义左列 200

落地建议 · 四阶段滚动，每阶段独立 commit + pif-ui 截图走查
阶段内容规模 / 风险
P0 地基新建 ui/tokens.rs 落全部令牌常量 + 单测锁定数值（仿 theme.rs 不变量测试）。零视觉变化；此后禁止新增硬编码尺寸。约半天 · 无风险
P1 值替换#8 勾色 → #9 次要钮描边 → #7 滚动条容器 → #4 danger 唯一化。全是近等值替换，视觉几乎无感，先销 4 条。约 1 天 · 低风险，一个 commit
P2 样板收敛#1 文字按钮：config_button 升级为通用按钮组件，先在 043 MCP 设置页试点走查再铺开；随后 #5 弹窗圆角、#3 图标档位（先统一关闭×=12、菜单图标=14 两个高频语义）。2–3 天 · 中风险
P3 收尾#6 行高四档、废 mb 补偿（项目行 33→32 有 1px 变化需走查）；#2 裸字号（markdown/终端为固定特例入册 tokens，不硬改 ui()）；#10 文档漂移回写。约半天 · 需走查
优先级理由：#1/#4 是后续新页面（042/043 一类设置页正密集产出）会照抄的样板，最优先统一，否则每新一个页面多欠一笔债；#2 带 bug 性质（调界面字号时那 11 处不动）；icon 全量 66 处不做一次性大扫除，改到哪个模块顺手收敛哪个模块。
