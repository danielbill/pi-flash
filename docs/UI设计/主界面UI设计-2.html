主界面UI设计说明

配套文件：主界面UI设计-2.html（可交互设计稿）· mist 主题。演示哈希：#collapsed 收起侧栏、#git 查看git面板、#term 开终端、#md 开预览、#new 新会话页、#search 会话搜索、#settings 设置、#nav 展开导航。

布局总览

topbar 40  [收放][─] [会话tab 激活][终端tab][文件tab] [─][□][×]
slp 300px 会话列表+文件树 上下整合面板 │ 内容区（聊天 / 终端 / md 预览 / 新会话页）
statusbar 40（项目 tab + 设置钮）│

整合面板（020-1）

会话列表与文件树整合为一个面板，上下两个子面板默认各占 50% 高度；分隔线可拖拽改比例，上推到底会话面板只剩控制栏、下拉到底文件树只剩操作栏（双击复位 50%）。子面板 = 控制栏 + 内容区；控制栏只放一个「最大化」钮：点击本面板最大化、另一面板自动收起到操作栏（无最小化钮，避免双最小化盲区），中间比例交给分隔线拖拽。会话控制栏左三（项目 / 会话 / 搜索，icon+文字）右二（列表切换 / 最大化，纯 icon）；文件树控制栏在原四钮最右加最大化。

三层色阶

  • chrome #dfe9e5 — topbar + statusbar
  • nav #eef4f1 — 项目/会话侧栏
  • content #f4f8f7 — 聊天 / 预览

选中语言一句话：选中会话 = 前景 10% 薄纱（非 accent）；活动项目行 = 加粗提字，无底色。

会话导航

右侧 14px 沟槽内段式 rail：高 75%、段上限 10（超出走桶映射）、常驻弱 accent；悬停展开 400px 发言列表，顶部 32px 总结栏「{n}条消息：用户{u}条 助手{a}条 工具调用{t}次」。

会话行状态槽

优先级：运行中旋转圈 > 错误红点 #c25460 > 警告黄点 #facc15 > 未读青蓝点 #3aa6d0。时间列 38px：刚刚 / N分钟 / N小时 / N天。

设置

七页：界面 / 模型 / 技能 / 扩展 / MCP / 其他 / 关于；模型·技能·扩展·MCP 为左列表 350px + 右详情分栏。主题七款：雾青·蔷薇·One Light·Nord Light·Ayu Light + Nord Dark·One Dark。
