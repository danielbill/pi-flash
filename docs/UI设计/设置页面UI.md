# 界面
title: 界面（Appearance）

设置内容：
1、主题
2、字体（三槽位：会话字体 / 面板字体 / 文档字体）
3、会话内容宽度（消息列 + inputpanel 同源）
4、内容显示开关（展示思考 / 部分操作隐藏 / 显示状态栏）
5、语言（置底）

## 主题
淡色主题放一排、深色主题放一排；每排固定 5 个等宽槽位（不足补空槽），当前内置九套 = 淡色 5（kitchen/mist/latte/rose/one-light）+ 深色 4（one-dark/nord-dark/pine/night-owl）。

主题配置写入 pi-flash 的 app_settings.json（不写 pi 的配置）。

## 字体
三槽位行（会话字体 / 面板字体 / 文档字体），每行 = 标签 + 250px 族下拉 + 100px 字号档下拉。
族下拉弹卡 250×400，第一行是 input 框用来快速筛选字体，列表每项以自身字体渲染。
字号档位：会话/面板共用 15/16/17/18；文档字体 16/18/20/22（不在档内的存档按就近档显示/高亮）。
字体大小改变时，要直接反应在界面上（所见即所得）。

## 会话内容宽度
滑块 180px（规范 §5.11）+ 左侧实时读数 `920 px`（mono、右对齐）；无「复位」钮（再拖回去即可）。
拖动即预览（只写内存），松手落盘到 `app_settings.json` 的 `chat_content_width`。
阈值：默认 920 / 最小 560 / **最大 1200** / **步进 20**。列宽是 `w_full().max_w(cap)` 的封顶值，小屏
自动取可用宽，与机器分辨率无关。窗口：还原尺寸
1180×760（`WINDOW_W/H`），最小尺寸 1180×600（`WINDOW_W_MIN/H_MIN`，宽度
同还原宽、高度留出老屏幕的任务栏空间）。
消息列、composer 胶囊、输入区功能条/状态带、新会话页内容带、ask 问卷卡读同一值（pi-web
`--chat-content-max-width` parity），改一处整列同宽。

## 语言
三个一行左对齐（radio：14 圆圈 + 6 内点，选中只加粗不变色）
