为输入面板新增「计划模式」

依据 031-1 需求与 ZCode 对照调研结论。闸门落在 pi 进程内（asset 扩展 plan_mode.ts），PF 侧只做状态投影与审批 UI。

##实施步骤

  • 扩展核心：状态机 / 三命令 / tool_call 硬闸 / 提醒注入 — assets/plan_mode.ts
  • 装配：全档位 -e 挂载 + 磁盘落盘 — tools_recipe.rs
  • 状态通道：setStatus("pf-plan") 拦截 → plan_enabled 字段 + disposition 校验
  • 菜单：工具菜单顶部「计划模式」+ 分隔线（正交勾选）
  • 审批弹窗：本原型对应件，复用 editor/markdown::render

##关键裁决

// block 而非摘工具：硬闸是唯一可靠执行点
fn on_tool_call(tool, input) {
  if plan_enabled && !read_only(tool) {
    return { block: true, reason: "计划模式：只读探索" }
  }
}

##风险与回滚

  • 扩展未装载时 /plan 会被当普通消息发出 —— 以 disposition:"handled" 校验兜底；
  • setActiveTools 下轮生效，硬闸不可省；
  • 回滚 = 摘掉 -e 一行，无持久化迁移。
