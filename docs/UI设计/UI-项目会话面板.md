设计核心：隐藏复杂度，减少第一层信息呈现，节省用户心智负担
设计参考： Chatgpt

项目会话面板，以下简称 psp

## 项目列表
![psp列表](image.bmp)

1、首行 【项目】 是个操作行， 有1个操作
  - 添加项目：对pi-flash而言就是打开本地文件夹

2、默认至多加载5个项目，顺序按照最后更新时间顺序排列，默认加载N个项目在 settings - 更多 中可设置

3、项目名称行也是操作行
![项目操作行](image_2.bmp)
- 鼠标悬浮该行时给出项目详细信息小浮窗，信息包括：
  - 短目录名
  - 全目录名
  - 包含几个对话
  - 最近更新时间（取项目内最新更新会话的更新时间）
  
- 点击该行该组收起展开，组内无会话时灰色字体显示【无会话】

- 右侧有2个操作
  - 【...】这是操作菜单，其中包含 1、在系统文件浏览器中打开 2、为该项目打开一个terminal（同时视图切换到文件树视图） 3、删除项目所有会话
  - 【+】添加一个新会话

## 会话标签
![会话标签示意图](image_3.bmp)
列表上不再展现时间，进一步简化信息，鼠标悬浮时给出详细信息弹窗，内容如下：
- 会话名称（默认取用户首次会话前20个字），点击可修改名字
- 最后活动时间距离当下时间
- 归属项目
- 分隔线
- 删除按钮
