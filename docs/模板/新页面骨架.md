# 新页面骨架（可复制 · 零字面量）

> 本页是**唯一该被复制的东西**：抄它，不要从 `gpui::div()` 起手。
>
> 配套：
> - 尺寸表 = `docs/UI设计/UI组件规范.md` §10（本文所有数字都在那张表里，本文不重复列数）
> - 组件入口 = `crate::ui::kit`（`crates/app/src/ui/kit/mod.rs`）
> - 守卫 = `scripts/check_ui_raw.py`（交互链出现裸几何字面量就红；`scripts/check_arch.sh` 第 4 条）

---

## 0. 铁律三条

1. **页面里不出现几何字面量**：不写 `.h(px(28.))`、`.rounded(px(5.))`、`.gap(px(4.))`。
   要高度用 `btn::MD_H` / `space::SP4` / `radius::CTRL`，要控件用 `ui::kit`。
2. **交互件不许自绘**：按钮 = `config_button` / `button`；开关 = `config_switch` / `switch_base`；
   输入 = `TextInput`；滑块 = `width_slider`；行 = `set_row` / `sidebar_item` / `group_header`。
3. **缺什么先加进库**：新组件落在 `ui/kit/`（或 `ui/`），尺寸同时写进 §10 表格，然后再用。
   绝不允许「这一页特殊，就地拼一个」。

---

## 1. 两栏页（左列表 + 右详情）

```rust
//! 示例页（<编号>-<名字>）：两栏标准页。
//! 骨架照 docs/模板/新页面骨架.md，组件一律来自 crate::ui::kit。

use gpui::{div, px, rgb};
use gpui::prelude::*;

use crate::ui::kit::*;
use crate::appearance::theme::theme as T;

pub(crate) fn page(chat: &Chat, weak: &gpui::WeakEntity<Chat>) -> gpui::AnyElement {
    let t = T();
    let rows: Vec<gpui::AnyElement> = chat.some_items.iter().map(|it| {
        sidebar_item(format!("x-row-{}", it.id), it.id == chat.some_selected)
            .child(icon("layers", 14., t.text_muted))
            .child(it.title.clone())
            .into_any_element()
    }).collect();

    div()
        .flex()
        .w_full()
        .h_full()
        .min_h_0()
        // 左：列表列（列宽走 LIST_W，禁止自己量）
        .child(
            sidebar_shell("x-sidebar")
                .w(px(LIST_W))
                .child(group_header("分组", None))
                .child(sidebar_list().children(rows)),
        )
        // 右：详情（内边距/行距/字号全在 detail_shell 里）
        .child(
            detail_shell("x-detail")
                .child(section_title("设置"))
                .child(set_row("标题", "说明文字", config_switch(
                    "x-sw", weak, chat.some_on, false,
                    |c, cx| c.toggle_some(cx),
                ), t))
                .child(field("名字", input))
                .child(config_button(
                    "x-save", weak, "保存", Btn::Primary, false, false,
                    |c, cx| c.save_some(cx),
                )),
        )
        .into_any_element()
}
```

要点：**整页没有一处 px 数值**——列宽 `LIST_W`、行高/内距/字号都在组件里；要新数值就是库缺件。

## 2. 单列设置页（一页几组行）

```rust
div()
    .id("x-single")
    .flex_1()
    .min_h_0()
    .overflow_y_scroll()
    .px(px(space::SP8))          // 页面外衬走 SP 令牌
    .py(px(space::SP7))
    .flex()
    .flex_col()
    .children(groups.iter().map(|g| {
        div().flex().flex_col().gap(px(space::SP6))   // 组间距 = SP6(12)
            .child(section_title(&g.title))
            .children(g.rows.iter().map(|r| set_row(&r.title, &r.desc, r.control(), t)))
    }))
    .into_any_element()
```

## 3. 新增控件位（先登记，再使用）

```
1) ui/tokens.rs        加常量（尺寸的唯一代码源）
2) ui/kit/<新件>.rs    写组件（唯一实现，带 //! 头注释说明用途+规范出处）
3) UI组件规范 §10       加表格行（尺寸、落点函数名）
4) 页面                 用；不许就地拼
```

## 4. 自查（提交前一行）

```bash
python scripts/check_ui_raw.py --list    # 你新写的交互件有没有裸几何字面量
```

命中就说明你在手搓：改成 `ui::kit` 组件或换 tokens；确属特殊控件（如自定义画布），在该
交互链里写 `// ui-raw: ok <理由>`，并在 §10 登记尺寸——**豁免必须留下理由**，否则下一个人
（或 agent）会照抄你的手搓。
