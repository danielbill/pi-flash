## 目标

做一份**纯 HTML 设计稿**（不碰 Rust 实现），呈现新主界面：最左侧加 100px 的 sessionListBar（项目标签列 + 运行时徽标）。设计定稿后再讨论 project 管理的实现。

## 产出

一个自包含 HTML 文件（内联 CSS/JS，零依赖，双击可开）：`tmp/design/session-rail.html`

### 画板 1：完整主界面（~1440×900）
1:1 复刻当前截图的其余部分（titlebar / 会话 dock / 聊天主列 / 状态栏），左侧插入新的 sessionListBar，配色取 `theme.rs` mist 调色板（bg #f4f8f7 / panel #e9f0ee / selected #d7e4df / accent #1e6559 / border #afc4ba…），观感与真实应用一致。

### sessionListBar 设计要点
- 宽 100px，垂直项目标签列，标签用项目目录名（过长截断 + hover tooltip）
- 每个标签上的徽标（按你消息的口径）：
  - **运行中**：●N（accent 色，N = 该项目活动 session 数，带呼吸动效）
  - **结束未读**：绿点 + N（N 个 session 结束未查看时点亮，数字缀后）
- 标签状态：激活项目（左侧 accent 竖条 + 选中底色）、运行中、有未读、空闲
- 排序（按 DeepSeek 讨论结论画，可后续调整）：运行中/有未读在前，其余按最后使用倒序
- 底部「+」添加项目入口
- 画板下方附**图例/注释区**：解释每种徽标、排序规则、激活/跟随语义——供我们逐条讨论定案

### 画板 2：折叠态（48px icon-only）
窄窗口行为：rail 折叠成图标列（首字母/文件夹图标 + 徽标保留），演示拖宽 88–160 与折叠两个极端。

### 数据样例
用你真实的项目名（pi-flash、pi_work、pi-web、大脑健身馆、个股调研等），各种徽标状态都有覆盖。

### 交互（轻量 JS，仅示意）
hover 高亮 + tooltip、点击项目切换激活态（纯视觉）、一个「折叠/展开 rail」演示按钮。
